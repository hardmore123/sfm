## 1. 各版本详细说明

### V1 `12.5新.py` — 前端原型（历史）

- **作用**：最早的声呐 SfM/BA 原型，验证"相对球坐标参数化"这一核心思路。
- **参数化**：路标用**相对基准帧球坐标** `(theta, phi, r)`，基准帧 = 首次观测该路标的帧（`landmark_base_indices`）。
- **残差**：首帧先验 + 里程计增量（逐维差分）+ 声呐重投影（像素 u,v）。
- **求解**：`scipy.least_squares(method='lm')`，无鲁棒核。
- **数据来源**：**观测和里程计硬编码在脚本内**（`my_obs`、`odom_deltas`，12 帧 × 15 路标），不读取 `.npy/.csv`。
- **投影模型**：`u = cx + fx·ψ`、`v = cy + fy·r`，并含仰角视场判断（`theta_min/theta_max`）。
- **价值**：V4 的相对球坐标参数化直接继承自此；欧拉约定 `R = Rz·Ry·Rx` 全项目由此统一。
- **局限**：数据硬编码、无鲁棒核、规模小，不能用于真实数据。

### V2 `ba_optimize.py` — 项目基线（冻结）

- **作用**：项目**正式基线**，第一个跑通真实数据的完整 BA。其余版本均由它派生，且被 V4/V5 作为库导入复用。
- **输入**：`poses_est.npy`(K,4,4)、`pose_frame_ids.npy`(K,)、`landmarks_final.npy`(M,3)、`tracks.csv`。
- **参数化**：位姿 6 维 `(x,y,z,roll,pitch,yaw)` + 路标世界笛卡尔 `(x,y,z)`。
- **四类残差**：
  1. 首帧先验（w=1000，消规范自由度）
  2. 里程计相对位姿（w=100，SE(3) 相对 + 旋转向量）
  3. 声呐重投影（w=1，像素量纲 `beam=A·θ+B`、`range=C·ρ+D`）
  4. 路标弱先验（w=1，拉向初值稳定欠约束点）
- **求解**：`trf` + 固定 Huber δ=20px，`max_nfev=200`。
- **内含三处临时补丁**（详见 `上游对接清单.md`）：
  - `build_track_to_landmark()` 暴力重投影反推 track→landmark（201/217，有配错风险）
  - `calibrate_pixels()` 从数据自标定像素映射
  - 里程计相对位姿由 `poses_est` 相邻帧差分反推，权重猜 100
- **可复用 API**（V4/V5 直接 `import ba_optimize as base` 调用）：
  `load_data` / `calibrate_pixels` / `build_track_to_landmark` / `euler_to_matrix` /
  `matrix_to_pose6` / `pose6_to_matrix` / `rot_to_vec` / `normalize_angle` / `save_ply` / `SonarBA`
- **输出**：`poses_optimized.npy`、`landmarks_optimized.npy/.ply`、`ba_result.png`、`ba_topview.png`。
- **实测**：重投影 RMS 5.29 → 1.01 px。

### V3 `ba_patent.py` — 专利开发版

- **作用**：为**专利方向**准备的独立副本，改动不影响项目基线。
- **与 V2 的唯一差异**：
  - 头部注明专利开发版及三线分工（基线/专利/论文）；
  - `main(folder, out_folder)` 支持**输入输出分离**——从项目根目录读数据，产物写回自身目录，与基线产物隔离。
- **算法内容**：**目前与 V2 完全一致**，尚未落地专利声称的改进。
- **计划落地**（专利核心创新）：相对球坐标 + 视场箱式硬约束 Ω + 软关联置信度 EM 交替求解。

### V4 `ba_improve.py` — ★最新（改进 1&2：几何可信）

- **对应**：`BA算法自身改进.md` 改进 1（相对球坐标参数化）、改进 2（欠约束路标识别 + 分类建模）。
- **改进 1**：路标由世界笛卡尔改为**相对基准帧球坐标 `(ψ, r, elev)`**，把声呐**不可观测的俯仰自由度显式隔离**成独立参数 `elev`，避免病态泄漏到笛卡尔三轴耦合。
- **改进 2**：对每个路标用其观测构建单点 `JᵀJ`(3×3)，按**特征值判据 λ₂/λ₃ < 20** 分良/欠约束：
  - 良约束 → 3-DOF 全优化；
  - 欠约束 → `elev` **移出优化状态**，在物理仰角孔径内网格搜索最一致值并固定，仅优化 `(ψ, r)`；
  - 外层**交替优化**（坐标下降 4 轮）：每轮先按当前位姿重搜 `elev`，再优化位姿与 `(ψ,r)`。
- **设计约束**：**不改动 V2**，`import ba_optimize as base` 复用其数据加载/关联/标定/里程计，保证三方对照口径一致；V2 保留为 fallback。
- **实测**（10 帧 / 217 路标 / 1641 观测）：
  - 路标 Z 位移 mean 0.269 → **0.082 m（↓69.5%）**，总位移 mean ↓67.3%
  - 重投影 RMS 1.01 → 1.21 px（略升约 0.2px，是"禁止用不可信自由度换低残差"的合理代价）
  - **关键发现**：判据下 198 个多帧路标**全部为欠约束**（λ₂/λ₃ 最小 25.69）→ 量化证明当前轨迹（前向平移+小幅偏航）落在退化运动区间，俯仰几何不可观测。
- **输出**：`landmarks_improved.npy/.ply`、`BA自身改进_测试结果.md`、
  `ba_improve_cloud.png` / `ba_improve_zdrift.png` / `ba_improve_metrics.png`。

### V5 `ba_improve34.py` — ★最新（改进 3&4：效率与鲁棒）

- **对应**：`BA算法自身改进.md` 改进 3（解析雅可比 + 稀疏求解）、改进 4（GNC + χ² 外点剔除）。
- **改进 3**：
  - 推导声呐重投影对位姿(6)/路标(3) 的**解析导数**；关键简化：`P_b = Rᵀ(P_w − t)` 使**平移雅可比 = −路标雅可比**；旋转用欧拉角解析导数 `(∂R/∂angle)ᵀ·d`；
  - 按 BA 二部图结构一次性**向量化填充稀疏 CSR** 交给 `trf`(lsmr)；
  - 里程计块仍用局部有限差分（仅 12 个相关参数，开销可忽略）；
  - 经有限差分校验，最大绝对误差 ≈ 3.7e-4。
  - **实测**：73.34s（数值稠密）→ 22.21s（数值+稀疏）→ **12.28s（解析+稀疏）**，≈**6.0× 加速**，三者 cost/RMS 一致（解等价）。
- **改进 4**：
  - **GNC**（Geman–McClure）：`μ` 从大退火到 1，外层 IRLS 重加权，内层复用解析稀疏雅可比；
  - **χ²(2, 0.99)=9.21** 门限做外点判定，判定外点权重置零后再用 Huber 做内点重优化；
  - 可控实验：在 `beam/range` 各注入 40–80px 大偏移，扫描 15/25/35% 外点比例。
  - **实测**（内点重投影 RMS，Huber → GNC）：15% 4.97→**3.60**；25% 8.05→**4.63**；35% 10.78→**2.76** px。
  - **诚实标注**：25% 档 GNC 位姿误差 0.189m 高于 Huber 0.092m，说明 GNC 对 `μ/c`/尺度估计与局部极小仍敏感，不宜宣称全面占优。
- **输出**：`BA自身改进34_测试结果.md`、`ba_improve34_gnc.png`（4 子图）。

### 工具 `view3d.py` — 交互式 3D 查看器

- 用鼠标旋转/缩放/平移查看优化结果；优先加载 `*_optimized.npy`，缺失则回退初值。
- 快捷键：`o` 叠加优化前点云、`f` 切换关键帧坐标轴、`r` 复位视角。
- 用法：`python view3d.py` 或 `python view3d.py --both`。

## 3. 运行说明（重要）

本文件夹是**归档副本**。所有脚本都用 `os.path.dirname(os.path.abspath(__file__))` 作为数据目录，
即**默认在脚本自身所在目录**找 `poses_est.npy` / `pose_frame_ids.npy` / `landmarks_final.npy` / `tracks.csv`。

因此两种运行方式：

**方式 A（推荐）** — 运行项目根目录的原件：
```powershell
cd "c:\Users\likunyuan\Desktop\private document\sfm"
python ba_optimize.py      # V2 基线
python ba_improve.py       # V4 改进1&2
python ba_improve34.py     # V5 改进3&4
python view3d.py           # 交互查看
```

**方式 B** — 在本归档目录内运行，需先把 4 个数据文件复制进来：
```powershell
cd "c:\Users\likunyuan\Desktop\private document\sfm\BA代码"
Copy-Item ..\poses_est.npy, ..\pose_frame_ids.npy, ..\landmarks_final.npy, ..\tracks.csv .
python ba_improve.py
```

> V4/V5 依赖 `import ba_optimize`，本目录已包含 `ba_optimize.py`，导入可正常解析。
> 环境：Python 3.14、numpy 2.5.1、scipy 1.18.0、matplotlib（Agg 后端出图）。
