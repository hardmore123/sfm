## 1. 论文的落脚点与两个创新点

**落脚点：声呐三维重建。** 两个创新点串行成闭环，不是并列的两件事：

```
         ┌─────────────────── ★I 可观测性判据 ───────────────────┐
输入      │  多视 BA → 位姿 + 稀疏地标                            │
声呐图像 →│  判据一：高度精度存在孔径决定的硬上限 τ_z^crit         │→ 哪些点的高度
序列      │  判据二：可反演性包线（四约束 C-I..C-IV）             │   多视做不到？
         └───────────────────────┬───────────────────────────────┘
                                 │ D_t（柱体水平位置）、z_s（高度）
                                 │ ← 这就是两创新点的**接口**
         ┌───────────────────────▼───────────────────────────────┐
         │  ★II 声学阴影补高度                                    │
         │  II-1：阴影远端 D_e 量测 → h = z_s(1 − D_far/D_e)      │→ 补上多视
         │  II-2：空间雕刻稠密化 → 包围壳                          │   缺的高度
         └───────────────────────┬───────────────────────────────┘
                                 ▼
                            三维重建结果
```

**为什么必须串行**：$h=z_s(1-D_{\rm far}/D_e)$ 里 $D_{\rm far}$ 和 $z_s$ 只能由 ★I（BA）提供，
$D_e$ 由 ★II 从图像量测。谁也离不开谁。
（历史教训：早期实现试图从待估的高度 $z_{\rm top}$ 反算 $D_t$，结果整个反演退化成代数恒等式——
这就是 `06_作废归档/` 里那批数字失效的根因，详见 Q1。）

## 6. 当前立住了什么

### 6.1 理论层（已查干净）

| 结论 | 公式 | 数值（ARIS 主档） |
|---|---|---|
| 高度 CRLB 取决于**仰角离散度**而非仰角本身 | $\sigma_{P_z}\approx\dfrac{\sigma_\rho}{\sqrt N\operatorname{std}(\varphi_k)}$ | 与实测吻合 6% 内 |
| 离散度门限 | $\Delta\varphi_{\min}=\dfrac{\sigma_\rho}{\sqrt N\tau_z}$ | $N{=}60$ 时 1.479° |
| **精度硬上限**（★I-1 的核心） | $\tau_z^{\rm crit}=\dfrac{\sqrt3\,\sigma_\rho}{\sqrt N\,\varphi_{\max}}$ | $N{=}10$ 时 **4.2 cm**，与 Aykin 的横向可分辨距离 $d_R=4.4$ cm 几乎相同 |
| 阴影反演 | $h=z_s\!\left(1-\dfrac{D_{\rm far}}{D_e}\right)$，$D_e=\sqrt{\rho_{\rm end}^2-z_s^2}$ | — |
| 有限尺寸物体 | $D_e=\dfrac{(D_t+r)z_s}{z_s-h}$（**轮廓远边缘**，非柱心） | 用柱心会有 +8.4 cm 偏置 |

**★I-1 的正式表述**（原表述"存在与运动方式无关的不可观测区"逻辑不成立，已作废）：

> 在给定观测数下，高度精度存在由孔径决定的硬上限 $\tau_z^{\rm crit}$，任何运动方式都无法突破。

### 6.2 数据层（`scene_set_main_f8`）

传感器全部落在 ARIS Explorer 3000 规格内：

| 项 | 值 | 规格对照 |
|---|---|---|
| 垂直孔径 | ±7.5° | 规格 14–15° ✅ |
| 方位孔径 / 波束 | 30° / 128 | ✅ |
| 量程 | 0.5–**15 m** | 探测模式（1.8 MHz）有效量程 15 m ✅ |
| range bin | **1600** ⇒ $\Delta\rho_{\rm bin}=9.07$ mm | 规格 3–19 mm，居中 ✅ |
| 下俯角 | 19° | 规格建议 15–20° ✅ |

$\Rightarrow\tau_z^{\rm crit}=4.18$ cm $\le\tau_z=5$ cm，**精度要求刚好可达**。

|---|---|---|---|---|---|---|---|

### 6.3 三项可报告结果

**① ★I-2 包线判据：3600 个 (帧, 列) 样本上 FP=0、FN=0。**
M4 的 TN=52 是有效负例（判不可反演且确实量不到远端）。
主档下 binding 约束是**量程**（54.6%），不是 C-III（24.1%）——因为 $\rho_{\max}$ 用了真实规格 15 m。

**② ★I-1 与 ★II 的互补性，在无泄漏数据上首次成立。**
M1 与 M2 **几何完全相同、只差轨迹起伏**（1.2 m vs 0.1 m）：
M2 的多视 CRLB 给出 48.57 cm（差 $\tau_z=5$ cm 要求 10 倍），而阴影反演给出 0.577 cm。
这是"阴影是多视的必要补充"的直接证据，也是两创新点串行的价值所在。

**③ 主档下 67.5–78.3% 的图像不含海底回波。**
±7.5° 孔径 + 19° 下俯的照明带只有斜距 $[10.09,\ 22.57]$ m，与量程 $[0.5,15]$ m 相交后仅剩 $[10.09,15]$ m。
独立可报告的工程结论：窄孔径 FLS 有效数据比例很低，采集规划必须显式优化照明带与目标的重合。

## 7. 引用这些数字时必须遵守的措辞纪律

这几条不是形式主义——每一条都对应一次已经踩过的坑。

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | $\sigma_{P_z}$ 是**解析 CRLB**，不得写成"BA 实测误差" | 没有跑 BA。BA 侧实测（R-X3）仍未做 |
| 2 | 720 条量测来自 60 帧 × 12 列，帧间几何高度相关，**不得当独立样本**做显著性检验 | 尤其 M2 近乎静止，帧间几乎重复 |
| 3 | 不得写"方位角完全不携带垂直信息" | 体坐标系下成立，世界系下声呐俯仰时不为零。斜距贡献是方位的 82 倍，应写"垂直可观测性由斜距主导" |
| 4 | 不得写"下俯角改善高度可观测性" | 实测水平 0° 与下俯 20° 的 $\sigma_{P_z}$ **完全相同**。纯旋转不改变声呐→地标的射线。下俯角的作用**仅在照亮海底以形成阴影** |
| 5 | 不得写"运动幅度越大盲区越小" | 已作废的旧叙事 |
| 6 | 孔径可见性用**体系**俯角；CRLB 的 $\operatorname{std}(\varphi)$ 用**世界系射线**俯角 | 两个不同的量，混用会同时错两处（见 Q6.1） |
| 7 | 复现失败不得写成"研究发现" | ★II-2 的 $E\le0.10$ 尚未达到，属实现精细度问题 |
