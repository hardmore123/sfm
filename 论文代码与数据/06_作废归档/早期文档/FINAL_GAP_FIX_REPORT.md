### 🟡 #2：V2 0% 误差的诚实标注

**问题**：S1-S5 数据 V2_noisy MAE = 0.30-0.58cm，但 V2 (无噪声) MAE = 0.00cm。读者易误以为"反演精度无限"。

**真相**（X3_CRLB_REPORT.md 已说明）：
- V2 0% 误差是"**几何 GT 自洽**"的数学必然
  - shadow.py V5.2 用物体几何 (cx, cy, h) 算 L_s = d·h/(z_s-h)
  - height_inversion V2 反演 h = L_s·z_s/(D_t+L_s) 严格还原
  - ⇒ h_inv == h_geom（恒等）
- V2_noisy 0.30-0.58cm 是"**实际工程精度**"（σ_L=5cm 高斯噪声）
- X3 验证 std/CRLB = 1.005-1.016（接近 1）— σ 传播完全自洽

**论文写作要点**：
- §4.2 必须区分"几何 GT 自洽证明"和"实际工程精度"
- 表格：V2 无噪声 = 0cm（自洽），V2 σ_L=5cm = 0.4cm（精度），Aykin = 200cm（V1 公式错）
- 关键洞察：V2 反演公式精确 = V1 基线公式 500× 改进

### 🟡 #3：feasibility 判据瞬时 z_s

**问题**：S6 几何（h=5.5, z_s=4.5, heave=1.2）AUV 实际 z ∈ [3.3, 5.7]，部分帧 z_s>5.5 时 h<z_s 可反演。

**修复**（详见 `_verify_feasibility_heave.py`，2.7KB）：

**新增 API**：
- `check_feasibility(z_s, ..., z_s_min=None, z_s_max=None)`：支持瞬时 z_s 范围
  - 严格场景：用 z_s_min 判定（C-IV 越界）
  - 概率场景：报告 z_s_max 时的可行性
- `check_feasibility_with_heave(z_s_center, heave_amp, ...)`：自动算 z_s_min/max + 模拟 100 帧算可反演比例

**S6 验证**：
- 旧版（z_s_center=4.5）：is_feasible=False ✓
- **新版严格（z_s_min=3.3）**：is_feasible=False ✓（更严格）
- **概率场景（100 帧模拟）**：fraction_feasible = **19%**（AUV 上顶点附近 19% 时间可反演）✓

**论文写作要点**：
- §3.2 明确"严格 vs 概率场景"判据
- S6 严格 = 不可反演，概率 = 19% 时间可反演（论文应讨论）
