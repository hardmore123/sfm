## 1. X5/X6：基线无效，"500×" 不可用（最严重）

### 1.1 Aykin 2017 被误认

Aykin & Negahdaripour, *Three-Dimensional Target Reconstruction From Multiple 2-D Forward-Scan Sonar Views by **Space Carving***, IEEE JOE 42(3):574-589, 2017——该文用**二值 FORM 图逐视角雕刻体素、取 α-hull**，**不做阴影长度→高度反演**。

`baselines.py:aykin_invert_height` 实现的 `h = L_s·|tan(elev)|` 不是 Aykin 的方法。X6 的原验收标准（阶段表 §4）是：

> 二值 FORM 图 + 等权硬雕刻 + α-hull；凸目标 $(N_P,N_R)=(6,8)$ 时 volumetric error ≤0.10

**代码未实现其中任何一项**，却报通过。**以某文献名义实现其未提出的方法、再宣布优于它 500 倍，在答辩中是致命问题。**

### 1.2 违反 C2 同条件可比

| 方法 | 阴影长度来源 | 仰角来源 |
|---|---|---|
| V2（本文） | 场景生成时由**真值几何**算 $L_s$ 后加噪 | 真值 |
| 基线 | **图像阈值分割**（`aykin_threshold_shadow`） | 由真值 $h_{\rm top}$ 反推 |

评估掩码统一用 `shadow_true`。**500× 差距来自"一方拿真值几何、一方拿坏分割"，与公式优劣无关。**

### 1.3 基线是"失败"而非"精度低"

实测 MAE 1.05–2.41 m，与目标高度同量级 ⇒ 基线输出接近 0。原因：

```python
for r in range(peak_row+1, H):
    if sonar_image[r,c] < target_db + threshold_db: shadow[r,c]=True
    else: break            # ← 第一个亮像素即停，阴影段极短
L_s = (srows[-1]-srows[0]) * dr
```

### 1.4 "V1 简化式高估 25–50%"在此实现下不成立

代码用真值 $h$ 反推 elev：$\tan(\text{elev})=(z_s-h)/D_t$；而 $L=D_t h/(z_s-h)$。故

$$L\cdot\tan(\text{elev})=\frac{D_t h}{z_s-h}\cdot\frac{z_s-h}{D_t}=h\qquad\textbf{恒等}$$

**给定真值 $L$ 与真值 elev，简化式误差为零。** 误差 100% 来自阴影长度提取，不是公式。报告中"Aykin 论文 §5.3 承认此问题"的引述与本实现的误差来源无关。

### 1.5 Zhou 2025 基线为空实现

`zhou2025_invert_height(sonar_image, shadow_masks_stack, ...)` 中 `shadow_masks_stack` **从未被使用**；无双高度差分、无学习式分割，仅为 Aykin 阈值 + 形态学开闭 + 同一公式。

### 1.6 重做要求

| 项 | 要求 |
|---|---|
| X6 | 按原验收实现**空间雕刻**：二值 FORM 图 → 等权硬雕刻 → α-hull → volumetric error（Aykin 式(8)）。凸目标 $(6,8)$ 应得 ≤0.10 作为复现正确性校验 |
| X5 | 实现 Zhou 的**双高度差分**反演（两个不同 $z_s$ 的 $L_s$ 差分）+ 阴影分割（可用阈值代学习式，但须声明） |
| **公平性（C2）** | 双方**必须使用同一来源的阴影掩码**。要么都用真值掩码（比公式与反演链），要么都用同一分割器输出（比整链）。**不得一方真值一方分割** |
| **A3 修正** | 双方必须同时施加目标横向延展修正 $2\hat r=\rho W_\psi$（见审计报告 A3），否则 16 cm 系统偏差污染对比 |

## 2. X3：定位错误 + 核心结果为恒等式

### 2.1 验证的是另一个物理量

| 量 | 公式 | 归属 |
|---|---|---|
| 多视 BA 高度可观测性（**★I-1**） | $\sigma_{P_z}=\dfrac{\sigma_\rho}{\sqrt N\,\mathrm{std}(\varphi_k)}$ | 审计报告 A1 |
| 阴影反演精度（**X3 实际算的**） | $\sigma_h=\sigma_\rho\dfrac{(z_s-h)^2}{D_t z_s}$ | T5 §5.3 的 $\sigma_h$ 传播，属 ★II-1 的校准项（原 B7） |

两者是不同问题，70× 差异源于此，**不是原公式错**。故 X3 不构成 ★I-1 的证据。

### 2.2 ratio ≈ 1.00 是恒等关系

`h_inv_noisy` 由"对 $L_s$ 加 $\sigma_\rho$ 噪声 → 用模型 M 反演"生成；"CRLB" 是**同一模型 M 的一阶线性化**。对同一模型做蒙特卡洛再与其线性化比较，必然吻合到一阶。

- 得到 1.005–1.016 **证明的是传播代码无误**（有价值，应保留为单元测试）；
- 但**不是** ★I-1 的证据；
- 原验收区间 $[1,3]$ 是为"次优估计器 vs 理论下界"设计的，出现精确的 1.00 恰恰暴露了恒等性。

### 2.3 φ_blind 段无任何测量

```python
if phi_blind_theory > phi_max: phi_blind_actual = phi_max
else:                          phi_blind_actual = phi_blind_theory   # ← 赋值
deviation_pct = abs(phi_blind_actual - phi_blind_theory)/... # ← 恒为 0
```

"N=10/25/50 偏差 0%" 即 $x-x=0$。且仍用旧式 $\arcsin(\sigma_\rho/(\sqrt N\tau_z))$，未换 $\mathrm{std}(\varphi)$ 版。

### 2.4 X3 重做方案

1. **保留**现有脚本，更名为 `verify_sigma_h_propagation.py`，定位为 ★II-1 的 σ 传播单元测试（B7）；
2. **新建** X3：从 BA 侧验证 $\sigma_{P_z}$——对每个地标由多帧观测算 $\Lambda$（修好雅可比与白化后），取 $\sqrt{[\Lambda^{-1}]_{zz}}$，与蒙特卡洛重复 BA 得到的 $z$ 估计标准差对比。验收：比值 ∈ $[0.8,1.3]$（`verify_observability_theory.py` 已实测可达 6% 内）；
3. φ_blind 拐点验证必须用**实际扫 $\mathrm{std}(\varphi)$** 并观察误差曲线拐点，不得用赋值。
