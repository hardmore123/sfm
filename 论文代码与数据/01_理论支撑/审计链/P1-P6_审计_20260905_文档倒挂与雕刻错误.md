## 2. 🔴 P2：`std(φ)` 版下"盲区占孔径 X%"不成立

### 2.1 错在哪

`feasibility.blind_fraction_curve`：

```python
phi_min = blind_angle_std(sigma_rho, N, tz)      # 返回 std(φ) 的门限
f = min(phi_min / phi_max, 1.0)                  # 当成 |φ| 的门限用
# 注释：“盲区占比：仰角绝对值 < phi_min 的概率”
```

**$\Delta\varphi_{\min}$ 是对"各视角仰角的标准差"的门限，不是对"仰角本身"的门限。** 二者物理含义不同：

| 量 | 由什么决定 |
|---|---|
| $\mathrm{std}(\varphi_{jk})$ | **轨迹**（heave/roll 幅度、目标在孔径内的停留） |
| $\varphi_j$ | **地标位置**（相对声呐的俯角） |

一个位于 $\varphi=5°$ 的地标，轨迹给它 $\mathrm{std}(\varphi)=3°$ 则可观测、给 $0.1°$ 则盲——**与它在孔径中的位置无关**。

**结论**：$\mathrm{std}$ 版下"盲区"**不再是孔径内的空间区域**，而是观测几何的属性。因此：

- `blind_fraction_curve` 的 $f=\Delta\varphi_{\min}/\varphi_{\max}$ **无物理意义**；
- `理论修正_T1-T6.md` §8.2 的"盲区占孔径 100% / 48% / 24%"表**失效**——而它正是当初选 $\tau_z=5$ cm 的第五条依据（"使孔径近乎均分、判别力最强"）。

### 2.2 解决

**保留**（这条推导正确）：孔径给 $\mathrm{std}(\varphi)$ 的硬上界 $\varphi_{\max}/\sqrt3$（均匀分布），故

$$\tau_z^{\text{crit}}=\frac{\sqrt3\,\sigma_\rho}{\sqrt N\,\varphi_{\max}}$$

**替换**：

| 原 | 新 |
|---|---|
| 盲区占比 $=\Delta\varphi_{\min}/\varphi_{\max}$（解析） | **盲地标比例 $=\Pr_j[\mathrm{std}(\varphi_{jk})<\Delta\varphi_{\min}]$（经验，需实际轨迹）** |
| 函数名 `blind_angle_std` | `min_elev_spread`（返回的是离散度门限，非角度位置） |
| `blind_fraction_curve(σ,N,φ_max,τ_z)` | `blind_fraction_curve(std_phi_per_landmark, σ, N, τ_z)`——**必须传入实际的 $\mathrm{std}(\varphi_{jk})$ 数组** |
| $\tau_z$ 曲线纵轴"孔径占比" | "该轨迹下盲地标比例" |

**$\tau_z=5$ cm 的依据需重述**（去掉失效的第五条，其余四条仍成立）：与 $d_R=R\,d\theta=4.4$ cm 同量级；对 0.5–2.5 m 目标为 2–10% 相对精度；ARIS 距离分辨率 3–19 mm 下可达；Feng 2024 水池 HD=2.25 cm 说明保守可达。**并补一条更强的**：$\tau_z^{\text{crit}}(N{=}10)=4.2$ cm 与 $d_R=4.4$ cm 几乎相同，说明垂直与横向精度天然同量级，$\tau_z$ 取 5 cm 恰在二者之上一点。

## 3. 🔴 P3：R-X6 空间雕刻的四处实现错误

### 3.1 主因——逻辑方向反了

```python
alive = np.zeros(n_vox, dtype=bool)          # 初始全 False
...
carved_this_frame[beam_idx[keep_mask]] = True
alive = alive | carved_this_frame            # ← 并集保留（OR）
```

空间雕刻的定义是"**初始全部体素存活，任一视角判为自由空间即删除**"（交集 / AND）。此处做成"初始全空、任一视角标记即保留"（并集 / OR），**方向完全相反**。

Aykin 的 $S\subseteq\tilde S$ 保证正来自 AND 累积。OR 会得到各视角可视锥的并集，是一个与场景几乎无关的膨胀体。这解释了三个自相矛盾的观测值：

| 观测 | 数值 | 用 OR 语义的解释 |
|---|---|---|
| `V_recon` 跨场景恒定 | 3.509（而 $V_{gt}$ 分别为 1.25 / 8.93） | 并集迅速填满可视锥，与场景无关 |
| `n_carved_pct` | 100.0 | 变量名为 carved 实为 alive；100% 是"全部保留"而非"全部删除" |
| `volumetric_error_strict` | 0.9975 | $\tilde V=3.509\gg V=1.252$ 且 $V_\cap$ 小 ⇒ $E\to1$ |
| `inclusion_pct` | 78.4%（应 100%） | 见 3.2 的 Bug2/Bug3 |

### 3.2 另外三处

| # | 错误 | 正确做法 |
|---|---|---|
| **Bug2** | `front_rho = form_rows.max()` 取**最远行** | leading edge 是**最近行** `form_rows.min()`。Aykin 明确只有 leading edge 可靠，trailing edge 受距离向拖尾与多径污染 |
| **Bug3** | $\rho>\rho_{\rm leading}$ 的体素被纳入判定 | 该区域是**遮挡/未知**，既不可雕除也不可算占据（占据栅格中的 unknown） |
| **Bug4** | `if len(form_rows)==0: continue` 跳过无回波波束 | **无回波意味着整条波束在量程内全为自由空间**——这是信息量最大的雕刻机会，绝不能跳过 |

### 3.3 正确实现（伪码）

```python
alive = np.ones(n_vox, dtype=bool)                       # 初始全存活
for n in range(N):                                        # 逐视角
    # ... 算 rho / i_theta / in_elev / in_range（现有代码可用）
    for th in beams:
        rows = np.where(FORM[n, :, th])[0]
        col  = (i_theta == th) & in_elev
        if len(rows) == 0:
            free = col & in_range                         # 整条波束自由
        else:
            rho_lead = range_axis[rows.min()]             # ← min，不是 max
            free = col & (rho < rho_lead - dr / 2)        # 仅前沿之前自由
        alive[free] = False                               # 删除 ⇒ AND 语义
        # ρ > rho_lead：遮挡，保持不动
```

### P6 $\sigma_\rho$ 口径三处不一致

| 出处 | 值 |
|---|---|
| ARIS 规格（`ARIS_EXPLORER_3000_PARAMS.md`） | 3–19 mm |

| 场景采样（600 bin / 25 m） | 41.7 mm |

**解决**：建立 `sigma_rho_ledger.md` 台账，为每类实验固定一个值并写明依据：

| 用途 | 取值 | 依据 |
|---|---|---|
| 主档理论计算 | **10 mm** | ARIS 3–19 mm 取中 |
| 主档仿真 | $\max(c/2B,\ \text{bin size})$ | 采样受限时以 bin size 为准，须在 meta.json 落盘实际值 |
