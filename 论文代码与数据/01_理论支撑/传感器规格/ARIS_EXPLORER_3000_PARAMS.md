## 0. 设备定位

ARIS Explorer 3000 是 Sound Metrics 公司的双频自适应分辨率成像声呐（Adaptive Resolution Imaging Sonar），专为水下 ROV/AUV 集成设计。**双频（1.8 MHz 探测 / 3.0 MHz 识别）** 自动切换，**最大耐压 300m**，是水下高分辨率成像的主流工业级传感器。

数据集论文：Valdenegro-Toro, Padmanabhan, Singh, Wehbe, Petillot. *The Marine Debris Forward-Looking Sonar Datasets*. OCEANS 2025 Brest.

## 1. 核心参数表

### 1.1 工作模式（双频自动切换）

| 模式 | 频率 | 水平波束宽度 | 垂直波束宽度 | 源级 | 有效量程 |
|------|------|--------------|---------------|------|----------|
| **探测** (Detection) | **1.8 MHz** | 0.3° | 14-15° | 195-206 dB re 1μPa@1m | **15 m**（@15°C 水温） |
| **识别** (Identification) | **3.0 MHz** | 0.2° | 14-15° | 195-206 dB re 1μPa@1m | **5 m**（@15°C 水温） |

### 1.2 几何参数

| 参数 | 值 | 备注 |
|------|----|------|
| **波束数** | 128 或 64 | 默认 128，64 模式帧率更高 |
| **波束间隔** | 0.25° | 128 模式 / 64 模式一致 |
| **水平视野 (FOV H)** | **30°** | 128 波束覆盖 128×0.25°=32°，中心化后 30° |
| **垂直视野 (FOV V)** | **15°** | 单帧仰角范围 |
| **量程** | 0.7 m - ∞ | 远程聚焦 |
| **距离分辨率** | **3 mm - 19 mm** | 物理 δρ = c/2B = 2.5mm（受采样限制） |
| **脉冲长度** | 4-24 μs（或 4-100 μs） | 长脉冲→远距；短脉冲→高分辨 |

## 2. 关键几何计算（与本论文相关）

### 2.1 像素-角度映射

- 128 波束模式：每像素 0.25° 方位分辨率，1° / 4 像素
- 64 波束模式：每像素 0.5° 方位分辨率

### 2.2 像素-距离映射

```
距离 bin = (c/2) × Δt = 1500 m/s × Δt
```
- 物理距离分辨率：c/(2B) = 2.5mm（3MHz 模式）
- 实际距离分辨率：3mm-19mm（受发射脉冲长度影响）

### 2.3 仰角孔径的物理意义

ARIS 是 2D 前视声呐，**单帧没有仰角分辨率**。30° H × 15° V 表示**瞬时孔径**：
- 水平 30° = 方位 FOV
- 垂直 15° = 仰角 FOV
- 这正是本论文的核心问题：**仰角不可测** → 必须用阴影反演或多视几何推断

## 3. 与仿真默认值的对比

| 参数 | ARIS 3000 实际 | 仿真 `Config` 默认 | 建议 |
|------|----------------|--------------------|------|
| 频率 | 1.8 / 3.0 MHz | N/A | 仿真不需要 |
| 方位 FOV | 30° | 130° (-65°, +65°) | 仿真用 130° 是 OK 的（更宽利于多目标） |
| 仰角 FOV | 15° | 34° (-17°, +17°) | 仿真 34° 比真实 15° 宽 |
| 量程 | 0.7-15m（探测）/ 0.7-5m（识别） | 6.0m | **仿真 6.0m 是合理的（介于两模式之间）** |
| 距离分辨率 | 3-19mm | 6.7mm（800 bin / 6m） | 仿真 6.7mm 比 ARIS 差 3-5×，可改进 |
| 波束数 | 128 | 512 | 仿真 512 是过采样，对应 0.25° 类似 |
| 帧率 | 4-15 fps | N/A | - |

### 3.1 仿真参数调整建议（基于 T7.1 阶段表）

按 `实施任务表_验收标准_阶段安排.md` §7.1：
- `range_max_m` 6.0 → **25-30 m**（适配真实量程）
- `range_bin_count` 800 → **1600**（30m/1600bin=18.75mm，接近真实 δρ）
- 平台 altitude 1.5 → **4-5 m**（满足 h ≤ 0.5 z_s）
- `fov_elevation_deg` ±17° → **固定下俯 15-20° + 小幅摆动**（更接近真实 MCM 构型）
- `heave_amplitude_m` 0.4 → **1.0-1.2**（仰角基线需达弧长 30-50%）
- 场景尺度 x∈[-3,3] → **~15 m**（地面距离 8-14m）

## 4. ARIS 3000 在数据集论文中的使用

### 4.1 数据采集配置

数据集中三个子集都是 ARIS Explorer 3000 在不同环境采集：
- **watertank-segmentation**：水槽中，1,868 张 320×480 标注
- **quarry-fullsize**：采石场实地，10 段连续序列（289-2,341 帧/段）
- **turntable-cropped**：转台，物体旋转 360°，15 个物体类别
- **watertank-cropped**：水槽裁剪，2,364 patch

### 4.2 物理意义

| 子集 | 物理环境 | 是否能反演目标高度 |
|------|----------|---------------------|
| `quarry-fullsize` | 真实海底，**自然声学阴影** | ✅ **最高价值**，可验证阴影反演真实性 |
| `watertank-segmentation` | 水槽，多类物体 | ✅ 用于分割训练（已有 1,868 标注） |
| `turntable-cropped` | 转台，物体整圈旋转 | ✅ **位姿近似已知**（转台角），可作多视真实验证 |

## 5. 论文用 ARIS 参数的注意事项

1. **量程与基线距离**：ARIS 实际 0.7-15m，本论文仿真 6m → 需要按 T7.1 调整为 25-30m 才能匹配真实场景
2. **仰角 FOV 物理边界**：ARIS 15° V → 任何基于 ±17° FOV 的反演算法都需要在论文中明确说明这是"模拟假设"，不是真实物理
3. **波束数差异**：ARIS 128 → 真实数据标注 320×480（每像素≈0.094°，是 128 波束的 ~2.7× 角分辨率）
4. **声学阴影在 ARIS 中物理存在**：quarry-fullsize 段包含自然阴影 → 这是真实数据阴影反演最直接的对照
