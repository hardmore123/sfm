#### 核心公式速查

| 量 | 公式 | ARIS 主档数值 |
|---|---|---|
| 高度 CRLB | $\sigma_{P_z}\approx\dfrac{\sigma_\rho}{\sqrt N\operatorname{std}(\varphi_k)}$ | 与实测吻合 6% 内 |
| 离散度门限 | $\Delta\varphi_{\min}=\dfrac{\sigma_\rho}{\sqrt N\,\tau_z}$ | $N{=}60$ 时 1.479° |
| **精度硬上限** | $\tau_z^{\rm crit}=\dfrac{\sqrt3\,\sigma_\rho}{\sqrt N\,\varphi_{\max}}$ | $N{=}10$: **4.2 cm**；$N{=}60$: 1.71 cm |
| 阴影反演 | $h=z_s\!\left(1-\dfrac{D_{\rm far}}{D_e}\right)$，$D_e=\sqrt{\rho_{\rm end}^2-z_s^2}$ | — |
| 有限尺寸物体 | $D_e=\dfrac{(D_t+r)\,z_s}{z_s-h}$（**轮廓远边缘**） | 用柱心会有 +8.4 cm 偏置 |
| $h\to$ 仰角 | $\hat e_j=\arcsin\dfrac{[R_b^\top(P_{\rm top}-t_b)]_z}{r_j}$ | **必须含 $R_b$** |
| heave 最优幅度 | $A_{\rm opt}\approx D_t\tan\varphi_{\max}$ | — |

**可反演性包线四约束**：

| 约束 | 表达式 | 含义 |
|---|---|---|
| C-I | $h<z_s$ | 目标低于声呐 |
| C-II | $h\le z_s(1-D_t/D_{\max})$ | 阴影远端在量程内 |
| C-III | $\dfrac{h\,D_t}{D_t^2+z_s(z_s-h)}\le\tan(2\varphi_{\max})$ | 孔径二阶项 |
| C-IV | $\theta_p$ 区间 | 下俯角范围 |

> **主档下 binding 是量程（54.6%），不是 C-III（24.1%）。**
> 原"C-III 先 binding"的前提是 $\rho_{\max}=40$ m（超规格 2.7 倍），已更正（Q5.3）。

#### $\sigma_\rho$ 两条链口径（关键，容易混）

| 链 | 观测量 | pipeline 中的形态 | 有效 $\sigma_\rho$ |
|---|---|---|---|
| **★I-1 多视 CRLB** | 斜距 $\rho$ | `tracks.csv` 的 `rho_m` 是**连续浮点**，只有 `range_index` 取整 | **= 注入噪声**（10 mm），range bin 不进入 |
| **★II-1 阴影反演** | 阴影长度 $L_s$ | 沿距离轴数 bin | **受 $\Delta\rho_{\rm bin}$ 量化限制** |

量化误差标准差是 $\Delta/\sqrt{12}$，**不是** $\Delta$。
与 ARIS 规格 3–19 mm 对表用 **bin 宽度**（规格给的是分辨率）；代入 CRLB 当噪声用 $\Delta/\sqrt{12}$。

## 措辞纪律（D 系列）

写作时必须遵守，每一条都对应一次踩过的坑：

| 不得写 | 应写 | 依据 |
|---|---|---|
| "方位角完全不携带垂直信息" | "垂直方向的可观测性由斜距主导" | 体系下成立、世界系下声呐俯仰时不为零；斜距贡献是方位的 **82 倍**（A4） |
| "下俯角改善高度可观测性" | "下俯角的作用仅在照亮海底以形成阴影" | 实测水平 0° 与下俯 20° 的 $\sigma_{P_z}$ **完全相同**（A5）；纯旋转不改变射线 |
| "存在与运动方式无关的不可观测区" | "在给定观测数下，高度精度存在由孔径决定的硬上限 $\tau_z^{\rm crit}$，任何运动方式都无法突破" | 不可观测条件是 $\operatorname{std}(\varphi)$ 小，而它恰由运动决定 |
| "运动幅度越大盲区越小" | —（作废） | T1 修正 |
| "盲区占孔径 X%" | "该轨迹下盲地标比例 Y%"（经验量） | $\Delta\varphi_{\min}$ 是离散度门限、非角度位置门限（P2） |
| 把复现失败写成"研究发现" | "尚未成功复现" | D9 |
| 无前提地报"反演精度" | 先证明估计量不是观测量的代数恒等变换 | **C7**（Q1 教训） |
