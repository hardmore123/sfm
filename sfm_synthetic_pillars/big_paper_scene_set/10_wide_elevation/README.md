# 宽仰角孔径 (±25°)

**目录**：`10_wide_elevation/`  **类别**：`sensor`

## 用途

约束松的成像几何

## 数据规模

- 帧数: 120
- 关键帧: 12
- Landmark: 60
- 观测: 2254
- 阴影像素: 4088518

## 声学配置

- beam×range: 512×800
- 方位 FOV: (-65.0, 65.0)
- 仰角孔径: (-25.0, 25.0)
- 距离: [0.2, 4.0] m
- 散斑σ: 0.2
- 噪声底: 45.0 dB

## 适用实验

- **不同分辨率/孔径对 BA 精度的影响**：分辨率 vs 精度曲线
- **创新一·M2 视场约束**：窄仰角（约束紧）vs 宽仰角（约束松）的影响
