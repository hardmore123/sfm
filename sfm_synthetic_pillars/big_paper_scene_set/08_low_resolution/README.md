# 低分辨率声呐 (128×200)

**目录**：`08_low_resolution/`  **类别**：`sensor`

## 用途

老声呐/低端配置，验证鲁棒性

## 数据规模

- 帧数: 120
- 关键帧: 8
- Landmark: 60
- 观测: 1653
- 阴影像素: 297495

## 声学配置

- beam×range: 128×200
- 方位 FOV: (-50.0, 50.0)
- 仰角孔径: (-15.0, 15.0)
- 距离: [0.3, 4.0] m
- 散斑σ: 0.2
- 噪声底: 45.0 dB

## 适用实验

- **不同分辨率/孔径对 BA 精度的影响**：分辨率 vs 精度曲线
- **创新一·M2 视场约束**：窄仰角（约束紧）vs 宽仰角（约束松）的影响
