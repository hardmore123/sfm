# 立方体（验证非柱面）

**目录**：`03_simple_cube/`  **类别**：`simple`

## 用途

验证几何模型泛化（柱→方）

## 数据规模

- 帧数: 120
- 关键帧: 12
- Landmark: 30
- 观测: 1358
- 阴影像素: 13684964

## 声学配置

- beam×range: 512×800
- 方位 FOV: (-65.0, 65.0)
- 仰角孔径: (-17.0, 17.0)
- 距离: [0.2, 6.0] m
- 散斑σ: 0.2
- 噪声底: 45.0 dB

## 适用实验

- **创新一·M1 软关联置信度**：在最小场景下验证置信度权重机制
- **创新一·M2 球坐标+视场**：单/双目标基础 sanity check
- **球 vs 柱**：对比声学阴影在不同几何下的形态差异
