# 极低 SNR（极端外点）

**目录**：`16_low_snr_extreme/`  **类别**：`aug`

## 用途

极限噪声测试，验证 GNC

## 数据规模

- 帧数: 60
- 关键帧: 12
- 目标数: 8
- Landmark: 240
- 观测: 5161
- 关键帧观测: 1071
- 目标像素: 11406
- 阴影像素: 5458336

## 声学配置

- beam×range: 512×800
- 方位 FOV: (-65.0, 65.0)
- 仰角孔径: (-17.0, 17.0)
- 距离: [0.2, 6.0] m
- 散斑σ: 0.6
- 噪声底: 60.0 dB

## 适用实验

- **sim-to-real 增强**：重相干斑训练对真实数据泛化的影响
- **创新一·M1 软关联 vs GNC 在低 SNR 下**：极低 SNR 下 GNC 优势验证
