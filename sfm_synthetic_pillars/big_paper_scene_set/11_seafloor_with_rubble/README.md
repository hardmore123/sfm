# 海底+散石（背景杂波）

**目录**：`11_seafloor_with_rubble/`  **类别**：`env`

## 用途

真实水下环境，杂波强

## 数据规模

- 帧数: 120
- 关键帧: 12
- Landmark: 200
- 观测: 5061
- 阴影像素: 4183052

## 声学配置

- beam×range: 512×800
- 方位 FOV: (-65.0, 65.0)
- 仰角孔径: (-17.0, 17.0)
- 距离: [0.2, 6.0] m
- 散斑σ: 0.2
- 噪声底: 45.0 dB

## 适用实验

- **创新一·M1 软关联鲁棒性**：杂波/多径下 RANSAC vs 软关联对比
- **创新二·M1 目标-背景分割**：评估在杂波下的目标检测能力
- **创新一·M4 加权曲面**：杂波下加权泊松抑制漂浮物
