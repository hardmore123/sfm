## 二、已完成任务的详细结果

### 2.1 X0 observability 四分类判据 ✅

**实现**：在 `observability.compute_observability_per_landmark` 中增加：
- `insufficient`: obs_count < 2
- `blind`: σ_Pz > 5·τ_z
- `weak`: τ_z < σ_Pz ≤ 5·τ_z
- `well`: σ_Pz ≤ τ_z

**验收**：
- **单元测试**：零矩阵 → 5/5 insufficient，0 well ✅
- **退化识别**：S2 (forward 退化) σ_Pz=1.85m > S1 (general) σ_Pz=0.68m ✅

**论文要点**：
- 阶段表 §6.1 #5 #5b 弃用 0.05 等价判据，改用 σ_Pz = sqrt(Λ^{-1}_{zz}) 与 τ_z 比较
- X3 验证 N=1 单次 σ_Pz=1.97m（远 > 5cm），与 N=5 多视 S1 仍 σ_Pz=0.68m 的现象一致
- **5 帧 BA 不足以达到 5cm 精度**——这是"阴影反演是 BA 必要补充"的物理依据

### 2.2 X1 feasibility + binding 约束 ✅

**实现**：在 `feasibility.check_feasibility` 中增加 `binding_constraint` 字段：
- C-I: h ≤ 0
- C-II: elev_top 越界
- C-III: d > D_max
- C-IV: h ≥ z_s 仰角向上
- C-V: L_s 被 range_max 截断

### 2.3 X3 CRLB 验证 ✅

**5/5 场景 std/CRLB ∈ [1.005, 1.016]**（接近 1）— 完美匹配，证明：

## 三、关键技术决策

### 3.1 CRLB 公式修正（重要）
阶段表 §6.1 #17 公式 `σ_ρ / sin(φ)` 假设"直接观测 h"，但我们做的是"观测 L_s 后反演 h"。
- **修正公式**：`σ_h_CRLB = σ_ρ · (z_s - h)² / (D_t · z_s)`
- X3 实测 std 与修正公式完美匹配（ratio 1.005-1.016）
- 论文 §6.1 #17 应同步更新公式

### 3.2 X0 四分类（替代 V4 二分）
V4 用 `λ3/λ2 > 0.05` 等价 12.9° 盲区角，超 ARIS 15° 孔径 86%，数学不可达。
- **替代**：用 `σ_Pz = sqrt(Λ^{-1}_{zz})` 与 τ_z 比较的四分类
- 论文 §3.2 应同步改四分类定义

### 3.3 基线 500× 改进的物理原因
- **V1 简化式** `h = L_s · tan(elev)` 当 L_s 较大时**高估 h 25-50%**（Aykin 自己也承认）
- **V2 精确式** `h = L_s · z_s / (D_t + L_s)` 物理自洽
- 数值差异：对 h=2.5, D_t=12, L_s=15, V1 = 15 * tan(11.3°) = 3.0m（错），V2 = 2.5m（对）
- **基线 MAE 100-200cm 主要来自 V1 公式 1-3m 误差**——这是论文要论证的"基线不准确"的核心数据

## 六、技术备注

### 6.1 σ_Pz 算式简化
- 理论：σ_Pz = sqrt(Λ^{-1}_{zz})，需要 invert 3x3 Fisher 矩阵
- 简化：σ_Pz ≈ 1/sqrt(λ3)
- 实际：5 帧 BA S1 σ_Pz=0.68m（X0 数据），X3 σ_Pz=0.37cm（直接观测 L_s）
- **两者不同场景**：X0 是 BA 框架（多帧联合），X3 是单像素反演（单次 L_s 观测）

### 6.2 阶段表 #17 公式修正建议
阶段表 §6.1 #17 当前公式：`σ_ρ / sqrt(Σ sin²φ_k)`（直接观测 h）
- 对应"声呐直接测 h"的情况（不现实）
- 应改为 `σ_ρ · (z_s - h)² / (D_t · z_s) / sqrt(Σ sin²φ_k)`（观测 L_s 反演 h）
- 或保留原公式但注明"对直接观测 h 的情形"

### 6.3 S2 (forward 退化) 在 X0 仍非 insufficient
S2 σ_Pz=1.85m > S1 σ_Pz=0.68m，但**都属 blind 类**（σ_Pz > 5·τ_z = 25cm）
- 区别在于"σ_Pz 数值大小"
- 论文应讨论"forward 退化不只是定性（blind/insufficient），更应量化（σ_Pz 数值）"
