## 🔍 关键发现

### 1. V5 (世界笛卡尔+稀疏解析+GNC) 是当前最佳
- **路标精度最佳**：5.77 cm（与 V2 基线 5.98 cm 持平，V4/V6 远差）
- **位姿精度次佳**：2.85 cm（仅次于 V2 的 2.78 cm）
- **速度**：12.6s（比 V2 快 **2.8×**，因解析 jac）
- **末 RMS 最低**：0.63 px

### 2. 球坐标参数化在 mixed 模式下表现糟糕
- V4 与 V6 都用相对球坐标，**所有 120 landmark 都被判为"欠约束"**（λ₂/λ₃ < 20 判据触发）
- 然后在 ±0.30 rad 仰角孔径内做网格搜索 → Z 被硬约束在孔径边界 → 路标 Z 误差 ~21 cm
- 这与 V4 论文报告的"**198/217 全部欠约束**"现象**精确复现**
- **建议**：球坐标参数化只适用于俯仰运动充足的良约束场景（`general` 模式）

### 3. GNC 对 clean 数据几乎无影响
- V5: 5.77 cm (GNC) vs 5.66 cm (无GNC) — 几乎相同
- 但 GNC 的真正价值在**外点鲁棒性**（V5 报告 25-35% 外点下 Huber→GNC 4.6→2.8 cm）
- 当前数据 sigma_θ=0.2° / p_miss=0.02 是"温和"噪声，GNC 不显著改变解

### 4. 解析稀疏 jac 加速 ~3×
- V5 (解析稀疏) 10.2s vs V2 (数值稠密) 34.7s → **3.4× 加速**
- 验证了 V5 报告"~6× 加速"的量级（在更小问题上加速比略低）

### 5. 速度排序（mixed 模式）
V6_无GNC (5.6s) < V5_无GNC (10.2s) ≈ V5+GNC (12.6s) ≈ V6+GNC (11.6s) < V4 (13.0s) < V2 (34.7s)

## 🎯 推荐用法

| 场景 | 推荐版本 | 理由 |
|---|---|---|
| **干净数据 + 快速** | V5 (无GNC) | 速度 10.2s，精度 5.66 cm |
| **干净数据 + 最佳精度** | V5 (GNC) | 末 RMS 最低 0.63 px，5.77 cm |
| **外点多（>15%）** | V5 (GNC) | GNC + χ² 鲁棒剔除 |
| **退化运动（纯前向）** | V2 或 V5 | 球坐标在退化下失效 |
| **一般 AUV 巡检** | V6 (GNC) | 球坐标对良约束情形更精确 |
| **阴影先验可用** | V6 + elev_prior | 充分利用 V6 留的接口 |

## 📈 改进方向（基于本次对比）

1. **球坐标参数化的"自动启用"机制**：
   - 在 well-constrained landmark 多的场景用球坐标（更精确）
   - 在 under-constrained 多的场景退回世界笛卡尔（更稳健）
2. **V5 → V6 接口补全**：把 V5 的解析稀疏 jac 移植到 V6 球坐标
3. **提供阴影仰角先验**（合成阴影 → elev_prior）：可缓解 V4/V6 的 Z 误差问题
4. **IMU/DVL 紧耦合**：在 V6 之上加 IMU 预积分层，进一步约束 Z
