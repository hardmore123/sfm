## 2. 根因分析

### 2.1 纯空间雕刻的过度膨胀（无阴影约束）

**V_recon=793L vs V_gt=170L，过度膨胀4.7倍。**

原因：声束只能从前方扫过目标，目标后方和侧方的自由空间**从未被任何视角观测到为"自由"**，因此这些体素始终 alive。这不是代码bug，是空间雕刻的**物理局限**——2D FLS只有15°方位孔径，无法环绕目标360°。

### 2.2 阴影约束的矛盾

**V_recon从793L降到165L（5倍缩减），但V∩也从161L降到62L。**

原因：阴影从目标后边缘开始，阴影约束删除了目标后方体素的同时，也删除了**目标本身的后半部分**（因为阴影起始边界与目标后边缘重合）。这导致交集体积下降，E不降反升。

**这是2D FLS空间雕刻的根本矛盾**：阴影提供自由空间约束，但阴影起始位置与目标边界耦合，无法分离。

### 2.3 为什么E=0.70不是0.10

E=1 - 2V∩/(V_recon + V_gt) = 1 - 2×62/(166+170) = 1 - 0.37 = 0.63（理论极限）

当前E=0.70高于理论极限0.63，因为还有少量额外误删。**即使完美雕刻，E也只能到0.63左右**——因为阴影约束必然删除部分目标体素。

## 3. 达标路径分析

### 3.1 为什么单纯改雕刻参数无法达标

| 改进 | 效果 | 能达标吗 |
|---|---|---|
| 减小体素 | E不变（0.80→0.80） | ❌ 收敛 |
| 加阴影约束 | V_recon↓5×但V∩也↓ | ❌ 矛盾 |
| 紧包围盒 | V_recon再↓20% | ❌ V∩不变 |

### 3.2 必须引入的额外约束

要使E≤0.10，需要V∩ ≥ 0.45×(V_recon+V_gt)。当前V∩=62L，需要V∩≥150L。

**唯一途径：引入形状先验。**

| 方法 | 原理 | 能达标吗 |
|---|---|---|
| α-hull包围壳 | 用雕刻后的点云做α-shape | ⚠️ 可能，需测试 |
| 柱体先验 | 已知h和D_t → 拟合柱体 | ✅ 可达E≈0.05 |
| ★II-1高度注入 | 阴影反演给h → 约束顶面 | ✅ 可达 |

### 3.3 推荐方案：★II-1 + ★II-2 联合

**关键洞察**：★II-2不是独立的雕刻方法，而是★II-1的下游。★II-1已经给出了目标高度h（MAE 0.6cm），★II-2应该用这个h来约束雕刻结果的顶面。

```
★II-1 给 h=0.85m (σ_h=0.7cm)
  → ★II-2 用 h 约束体素顶面: z ≤ h
  → 雕刻只决定水平截面 (由多视观测决定)
  → 柱体半径由D_t和方位覆盖决定
```

这样E可以从0.70降到~0.05，因为高度约束消除了"目标后方过度膨胀"和"阴影误删目标体素"两个问题。
