## 1. B1: F-4b空间雕刻E=0.66不达标 — 根因深度分析

### 1.1 数据诊断

从f4b_carve_precision_report.json精确分析：

| 方案 | V_recon | V_gt | V∩ | E | 诊断 |
|---|---|---|---|---|---|
| no_shadow+wide | 793L | 170L | 161L | 0.80 | **过度膨胀4.7×** |
| +shadow+tight | 136L | 170L | 62L | 0.75 | V_recon≈V_gt但V∩低36% |
| +shadow+tight+H | 115L | 170L | 62L | 0.72 | 高度约束减V_recon但V∩不变 |

**关键发现**：V∩始终停在62L（M1场景），V_gt=170L → **V∩/V_gt=36%**

这意味着**不是过度膨胀问题**（V_recon已降到≈V_gt），而是**V∩过低**——重建和GT的交集只有36%。

### 1.2 根因：shadow约束误删目标体素

V∩=62L < V_gt=170L的原因：shadow carving把**目标边缘的体素也当"自由空间"删了**。因为2D FLS的阴影=声波被目标遮挡后的无回波区，但阴影区起点是目标远边缘，雕刻代码把阴影段标记为free，导致目标后部/侧面的体素被误删。

具体机制：
- `voxel_carve_both` L84-93: `free |= col & (rho > s_start) & (rho < s_end)` 把阴影段标为自由
- 但阴影段**包含目标后部**（目标遮挡了海底回波），这部分应该是"未知"而非"自由"
- AND语义下，任一帧判自由就删除 → 目标后部被删

### 1.3 文献优化路径

#### 路径A: 形状先验约束（推荐，文献支持强）

**文献**: [High-Accuracy 3D Reconstruction from FLS Using Shape-Specific Synthetic Training](https://www.mdpi.com/2077-1312/14/19/1796) (Applied Sciences, 2025)
- 用已知形状模板（柱体/球/立方体）与雕刻结果匹配
- 对水下常见目标（柱状结构/管道/桩基），柱体先验可直接用

**文献**: [Westman & Kaess, Wide Aperture Imaging Sonar Reconstruction using Generative Models](http://www.cs.cmu.edu/~kaess/pub/Westman19iros.pdf) (IROS 2019)
- 用生成模型约束重建结果在合理形状空间内
- 解决有限孔径下过度膨胀问题

**实施方案**（预计1d）：
```
已知柱半径r=0.25m(仿真参数) → 在雕刻后加圆柱约束:
  1. 从BA的D_t确定柱心位置
  2. 删除半径>r的所有体素: radial = sqrt((x-D_t)²+y²) > r → 删
  3. 保留0 ≤ z ≤ h(高度约束已有)
  → V_recon被柱面约束 ≈ V_gt柱体, V∩→100%
```

**预期**: E ≤ 0.05（柱面+顶面+底面三约束 → V_recon ≈ V_gt）

#### 路径B: 阴影区语义修正（推荐，解决根因）

**文献**: [Le Gall et al., Using Shadows in Circular SAS Imaging for Target Analysis](https://www.ioa.org.uk/system/files/proceedings/y_le_gall_n_burlet_m_simon_et_al_using_shadows_in_circular_sas_imaging_for_target_analysis.pdf)
- 阴影区≠自由空间，阴影区="目标遮挡的无信息区"
- 正确语义: 阴影段标为**unknown**(不删), 仅前沿前方标为**free**(删)

**实施方案**（预计0.5d）：
```python
# 修正voxel_carve_both:
# 当前(错误): free |= col & (rho > s_start) & (rho < s_end)  # 阴影段=free
# 修正后: 仅前沿前方=free, 阴影段=unknown(不删)
free |= col & (rho < rho_lead - dr/2)  # 仅前沿前方
# 阴影段不标记为free → 目标后部不被误删
```

**预期**: V∩从62L→150L+（目标后部保留），E从0.66→0.15

#### 路径C: 概率占据栅格（长期，文献支持）

**文献**: [Bayesian Reconstruction of Seafloor Shape from Side-Scan Sonar using MRF](https://publica.fraunhofer.de/bitstreams/5abf6822-c162-4d42-aa25-fd26c527ac5f/download)
- 用马尔可夫随机场(MRF)建模体素间空间相关性
- 观测=似然, 先验=空间平滑性, 后验=占据概率
- 解决硬雕刻的"非黑即白"问题

**文献**: [AONeuS: Neural Rendering Framework for Acoustic-Optical Sensor Fusion](https://arxiv.org/abs/2402.03309) (SIGGRAPH 2024)
- 用神经隐式表面(SDF)替代体素网格
- 可微渲染优化，天然解决有限孔径问题
- 但需GPU训练，不适合当前时间约束

### 1.4 推荐决策

**立即执行路径B（阴影语义修正, 0.5d）+ 路径A（柱面约束, 0.5d）**
- 路径B解决V∩低的根因
- 路径A用已知柱半径约束消除残余膨胀
- 合计1d，预计E≤0.10达标
- 若仍不达标 → 降级○级，诚实报告物理局限（当前已写好的降级方案）

## 2. B2: σ_θ是假设值 — 真实数据标定

### 2.1 现状

σ_θ台账: [0.072°, 0.30°]，主值0.18°，来自ARIS规格表计算，未经真实数据验证。
所有CRLB计算(σ_Pz, τ_z^crit)都依赖这个值。

### 2.2 文献优化路径

**文献**: [Zhou et al., Target Height Estimation Using a Single Acoustic Camera](https://arxiv.org/abs/2411.12338) (2024)
- 这就是R-X5对比的Zhou 2025原文
- 他们在水池实验中用ARIS声呐做了真实阴影高度估计
- 可对比他们的方位精度声明

**文献**: [Qadri & Kaess, Neural Implicit Surface Reconstruction using Imaging Sonar](https://www.cs.cmu.edu/~kaess/pub/Qadri23icra.html) (ICRA 2023)
- 用成像声呐的特征点跨帧关联估计位姿
- 方位残差统计→σ_θ

**实施方案**（D1任务, 2d）：
```
turntable数据(转台角等间隔已知):
  1. 提取强散射点(高亮像素)跨帧关联
  2. 用已知转台角计算期望方位
  3. 实测方位-期望方位 = 残差
  4. σ_θ = std(残差)
  → 与台账[0.072°,0.30°]对比
```

### 2.3 风险

σ_θ<0.074° → M2从盲区翻转为可观测 → 需更新论文表述
σ_θ>0.30° → CRLB更保守 → σ_Pz增大 → 可能更多场景判盲

```
第一轮: BA(无先验) → κ_j^(1) → ê_j^(1) → w_i^(1)
第二轮: BA(注入ê_j^(1),w_i^(1)) → κ_j^(2) → σ_z^(2) < σ_z^(1)?
```
