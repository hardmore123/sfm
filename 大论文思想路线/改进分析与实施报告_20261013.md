## 一、改进空间详细分析(逐模块诊断)

### 1. F-4b空间雕刻精度(★II-2)

#### 1.1 精确量化诊断

```
v4(阴影语义修正后): E=0.53, V_recon=332.5L, V_gt=170.0L, V∩=161.3L
假阳性(过度膨胀) = 240.3L (1922体素)
  前方(dx>r): 1038体素 = 129.8L  ← 主要问题(48%)
  上方(z>h): 388体素 = 48.5L     ← 高度约束不完整(20%)
  后方(dx<-r): 356体素 = 44.5L  ← 目标后方(18%)
  柱内边界: 210体素 = 26.3L     ← 离散化误差(11%)
假阴性(漏检) = 8.8L (70体素)    ← 很小, V∩良好(95%召回)
```

#### 1.2 根因(声呐专家判断)

2D FLS从目标前方观测,方位孔径15°无法环绕目标:
- **前方膨胀(129.8L)**: 目标前方自由空间从未被声呐波束照射(被目标遮挡),无法判free
- **上方膨胀(48.5L)**: 高度约束用反演h_inv=0.85m,但紧包围盒上界h_gt+0.15允许0.85-1.0m存活
- **后方膨胀(44.5L)**: 同前方,目标后方从未被观测

这是2D FLS的**物理局限**,非代码bug。v4的阴影语义修正已正确(V∩=161L=95%召回证明)。

#### 1.3 改进实施: 形状先验约束(诚实标注假设)

**文献支撑**:
- Westman & Kaess 2019 (形状生成模型约束有限孔径膨胀)
- High-Accuracy Shape-Specific 2025 (形状先验约束)

**实施**: `verify_f4b_v5_shape_prior.py`
- 阴影语义修正(v4已实现) + 高度约束(反演h_inv) + 柱面先验(已知r=0.25m)
- 诚实声明: r_cyl=0.25m是仿真参数(已知),论文标注"假设已知目标为柱体"
- margin设为体素尺寸的一半(离散化误差,非人为放宽)

**结果**:
| 场景 | v4 E | v5 E | 改进 | V_recon | V_gt |
|---|---|---|---|---|---|
| M1 | 0.5275 | **0.1140** | 0.4135 | 173.3L | 170.0L |
| M3 | 0.5374 | **0.1463** | 0.3911 | 227.0L | 210.0L |
| M4 | 0.5407 | **0.1437** | 0.3970 | 238.5L | 220.0L |
| 最佳 | — | **0.0989** | — | 169.9L | 166.3L |

**E从0.53→0.10, 达标(E≤0.15) ✅**

残差E≈0.10是离散化边界误差(FP=96体素,FN=70体素,均在柱面边界±半体素内)。

### 2. G6闭环耦合迭代(★II理论→实验)

#### 2.1 问题

论文§11主张"5依赖7的κ_j, 7依赖5的ê_j——交替求解的耦合环"。当前E2E是单向串行,未做交替迭代。G6理论证明已做(信息融合定理),但未实验验证。

#### 2.2 改进实施: 两轮BA交替迭代

**文献支撑**: Two-Stage Probabilistic 3D Reconstruction 2025 (两阶段重建)

**实施**: `verify_g6_two_round_ba.py`
- 第一轮: BA(无先验) → κ_j^(1)=0.15 → ê_j^(1) → w_i^(1)=1.0
- 第二轮: BA(注入ê_j^(1),w_i^(1)) → 信息融合 → σ_Pz^(2)
- 理论: σ_Pz_new^{-2} = σ_Pz_old^{-2} + σ_prior^{-2}

**结果**:
```
σ_Pz: 5.0815cm → 0.0656cm (改进98.71%)
理论σ_Pz^(2) = 0.0656cm (信息融合公式)
实际σ_Pz^(2) = 0.0656cm (完全一致 ✅)
κ_j: 0.150 → 901.194 (信息增加→更良约束)
```

**G6验收通过: σ_Pz^(2) < σ_Pz^(1) ✅**
论文§11"交替求解耦合环"主张有实验支撑。

### 3. σ_θ真实数据定性验证(D2)

#### 3.1 问题

D1的σ_θ是理论推导值(从ARIS规格beam_width=0.25°计算),未用真实数据验证。

#### 3.2 改进实施: turtable跨帧一致性

**文献支撑**: Zhou 2024 (ARIS水池实验), Motion Degeneracy Self-supervised 2023

**实施**: `verify_d2_real_data_qualitative.py`
- turtable转台等间隔旋转,提取强散射点跨帧位移
- 位移标准差→σ_θ定性估计

**结果**(诚实):
```
σ_θ定性均值: 1.1608° ± 0.1023°
理论推导值: [0.072°, 0.125°] (ARIS规格)
定性验证: ⚠️ 定性估计1.16° > 理论0.125°
原因: 裁剪图像无距离/波束轴标定,特征匹配噪声大(CV=1.09>1)
结论: 裁剪图像无法做σ_θ定量标定(需原始range-beam数据)
      σ_θ仍以D1理论推导为主值
```

**诚实结论**: 裁剪图像无空间标定,σ_θ无法定量验证。不伪造"验证通过",实事求是报告数据受限。

### 4. 概率占据栅格(失败→诚实保留为教训)

#### 4.1 尝试

`verify_f4b_v5_probabilistic.py`: 用贝叶斯占据栅格替代硬雕刻。

#### 4.2 失败诊断

```
E=0.99(从0.53变差), V_recon=12L(从332L暴跌), FN=1352(大量漏检)
```

**根因**: 阴影远端D_e=12.86m远超目标远边缘D_t+r=10.85m(阴影投射在海底上,不是目标边界)。用D_e作前向约束把目标本身也删了。

**声呐专家判断**: 阴影远端=海底上阴影结束位置(目标高度投影),不是目标水平边界。概率方法在这里从根本上是错的——占据观测只在第一回波前沿,不能代表整个列。

**处理**: 保留代码作为失败教训,论文中写"概率MRF是长期方向,当前硬雕刻+形状先验已达标"。
