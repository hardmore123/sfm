## 二、核心瓶颈的文献改进思路

### 1. C1: F-4b空间雕刻E=0.53不达标

#### 1.1 问题本质

修正后(删除柱面先验循环论证)E=0.53。根因：2D FLS的15°方位孔径无法环绕目标→后方自由空间从未被观测→过度膨胀(V_recon=333L vs V_gt=170L)。

阴影语义修正解决了V∩(62L→161L)，但**V_recon仍为V_gt的2倍**——这是2D FLS的**物理局限**，非代码bug。

#### 1.2 文献改进路径

**路径1: 概率占据栅格替代硬雕刻（推荐，文献支撑强）**

文献：[Bayesian Reconstruction of Seafloor Shape from Side-Scan Sonar using MRF](https://publica.fraunhofer.de/bitstreams/5abf6822-c162-4d42-aa25-fd26c527ac5f/download)
- **核心思路**：用马尔可夫随机场(MRF)建模体素间空间相关性
- **改进**：观测=似然(有/无回波)，先验=空间平滑性，后验=占据概率
- **解决**：硬雕刻的"非黑即白"问题→后方未观测区获得先验概率而非直接保留
- **适用**：解决过度膨胀——未观测区不保留为"占据"，而是获得基于邻域的先验

文献：[3D Occupancy Mapping Framework Based on Acoustic Camera](https://www.sciencedirect.com/science/article/pii/S2405896318332683)
- 声学相机的3D占据栅格框架
- 用贝叶斯更新替代硬删除
- 每帧观测后更新体素占据概率，非观测区维持先验

**实施方案**：
```
当前: alive[free] = False (硬删除, AND语义)
改进: P(occupied|obs) = P(obs|occ)·P(occ) / P(obs) (贝叶斯更新)
     - 有回波区: P(occ)↑
     - 无回波+在视场内: P(occ)↓ (但不归零)
     - 未观测: P维持先验(基于邻域MRF)
验收: P>0.5的体素构成重建, E重新计算
```

**路径2: 形状先验约束（诚实标注假设）**

文献：[High-Accuracy 3D FLS Using Shape-Specific Synthetic Training](https://www.mdpi.com/2077-1312/14/19/1796) (2025)
- 用已知形状模板(柱/球/立方体)与雕刻结果匹配
- **关键**：必须诚实标注"假设已知目标形状"作为前提条件

文献：[Westman & Kaess, Wide Aperture Sonar Generative Models](http://www.cs.cmu.edu/~kaess/pub/Westman19iros.pdf) (IROS 2019)
- 生成模型约束重建在合理形状空间
- 解决有限孔径过度膨胀

**实施方案**（诚实版）：
```
论文明确声明: "假设已知目标为柱体(r=0.25m), 用形状先验约束"
1. 从BA的D_t确定柱心
2. 从★II-1反演h确定柱高
3. 删除柱体外部体素(radial>r且z>h)
4. 论文诚实写: "形状先验将E从0.53降至0.10, 但依赖已知柱半径假设"
```

**路径3: 多路径回波抑制（辅助）**

文献：[Removing Multi-Path Echoes in Underwater 3D Reconstruction](https://www.sciencedirect.com/science/article/abs/pii/S0167865525000078) (2025)
- 多视角一致性检测多路径回波
- 减少假回波导致的假自由空间判定

#### 1.3 推荐决策

| 优先级 | 路径 | 估时 | 预期E | 诚实度 |
|---|---|---|---|---|
| P0 | 路径2(形状先验,诚实标注) | 0.5d | ≤0.10 | ✅标注假设 |
| P1 | 路径1(概率MRF) | 3d | ~0.20-0.30 | ✅无需假设 |
| P2 | 路径3(多路径抑制) | 1d | 辅助 | ✅ |

**推荐**：执行路径2(诚实标注形状先验假设)+路径1(概率MRF作为长期改进)

### 2. C2: σ_θ是理论值

#### 2.1 问题本质

D1已改为"理论推导"(从ARIS规格beam_width=0.25°计算σ_θ∈[0.072°,0.125°])。真实数据(turntable/quarry)为裁剪图像无完整beam几何，无法直接标定。所有CRLB计算依赖这个理论值。

#### 2.2 文献改进路径

**路径1: 自监督学习估计仰角（最新，直接相关）**

文献：[Motion Degeneracy in Self-supervised Learning of Elevation Angle Estimation for 2D FLS](https://www.robot.t.u-tokyo.ac.jp/~yamashita/paper/B/B304Final.pdf) (东京大学, 2023)
- **核心思路**：用自监督学习从声呐图像直接估计仰角
- **改进**：无需转台标定，从运动中学习方位-仰角映射
- **解决**：裁剪图像无beam几何的问题——学习端到端映射
- **局限**：需训练数据，且运动退化时失效(与本文★I-1同构)

**路径2: 特征点跨帧关联统计残差（传统）**

文献：[Qadri & Kaess, Neural Implicit Surface Reconstruction using Imaging Sonar](https://www.cs.cmu.edu/~kaess/pub/Qadri23icra.html) (ICRA 2023)
- 用成像声呐特征点跨帧关联估计位姿
- 方位残差统计→σ_θ
- **问题**：需特征点关联，裁剪图像仍受限

文献：[Huang & Kaess, Towards Acoustic Structure from Motion](https://www.cs.cmu.edu/~kaess/pub/Huang15iros.html) (IROS 2015)
- 声学SfM框架，方位残差可直接统计

**路径3: Zhou 2025的真实数据声明（对照）**

文献：[Zhou et al., Target Height Estimation Using Single Acoustic Camera](https://arxiv.org/abs/2411.12338) (2024)
- 用ARIS声呐在水池实验做真实阴影高度估计
- 可对比其方位精度声明(若有)
- **R-X5已对比，本文单次0.116cm优于Zhou双高度0.273cm**

#### 2.3 推荐决策

| 优先级 | 路径 | 估时 | 可行性 | 说明 |
|---|---|---|---|---|
| P0 | 理论推导(已完成) | 0d | ✅ | 从ARIS规格推导，有下界支撑 |
| P1 | quarry定性验证(D2) | 2d | 中 | 无位姿真值，只报定性一致性 |
| P2 | 自监督学习 | 5d+ | 低 | 需训练数据+GPU，时间不够 |

**推荐**：保持理论推导为主值，D2做quarry定性验证(跨帧一致性)，论文诚实写"σ_θ为理论推导值，有ARIS规格下界0.072°支撑"

## 三、待修★★★问题的具体改进方案

### 1. B1: gen_scenes D_far用GT（★★★）

#### 问题

`gen_scenes_main_f8.py:209`: `P_top = np.array([D_T, 0.0, h])` 用GT柱心坐标算D_far，注入噪声只是给GT加扰动。leak_free已改False(诚实标注)，但实现仍用GT。

#### 改进方案

**方案A: 独立BA模拟（推荐，文献支撑）**

文献：[Huang & Kaess, Acoustic Structure from Motion](https://www.cs.cmu.edu/~kaess/pub/Huang15iros.html)
- D_far应来自BA的地标水平位置估计，不是GT
- 用ba_unified.py跑BA→输出D_far估计→喂给反演

```
1. 生成场景(已知GT)
2. 从声呐图像提取特征点(强散射点)
3. ba_unified.py跑BA→输出landmark估计(D_t_est, z_s_est)
4. D_far_est = D_t_est + r_cyl(假设已知r)
5. h_inv = invert(rho_end, D_far_est, z_s_est)  # 用BA估计,非GT
6. 误差 = h_inv - h_gt  # 真实误差(含BA噪声)
```

**方案B: 噪声注入增大（当前方案的诚实版）**

当前σ_Dt=0.02m(2cm)。若BA实际精度更差，增大到0.05m(5cm)更保守。

**推荐**：方案A(独立BA模拟)最诚实，但需1d实现。方案B(增大噪声)0.1d，但仍是"GT加噪"非独立BA。
