## 1. ★I-1 T7双通道CRLB

### 1.1 论文推导（理论修正_T1-T6.md §9.1）

**斜距通道**：Fisher信息 $\Lambda_\rho=\sum_k \nabla\rho_k^\top\nabla\rho_k/\sigma_\rho^2$，对2×2 $\Lambda_\rho$ 求逆，用Lagrange恒等式：

$$\sigma_{z,\rho} \approx \frac{\sigma_\rho \cos\bar\varphi}{\sqrt{N}\,\text{std}(\varphi_k)}$$

**方位通道**（时变横滚激活）：$\nabla_P\theta_k \approx (R_k e_y)^\top/\rho_h$，对世界z的分量为 $\cos\theta_p\sin r_k/\rho_h$：

$$\sigma_{z,\theta} \approx \frac{\bar\rho\,\sigma_\theta}{\sqrt{N}\,\text{std}(r_k)\cos\theta_p}$$

**两通道合成**（近似正交，信息相加）：

$$\sigma_{P_z}^{-2} \approx \sigma_{z,\rho}^{-2} + \sigma_{z,\theta}^{-2}$$

### 1.2 代码核查（feasibility.py:257-290）

```python

# 方位通道 (L285-286)

# 双通道合成 (L287-289)

s = inv2 ** -0.5
```

**逐项对照**：
- σ_z,ρ代码 `sigma_rho * cos(phi_bar) / (sqrt(N) * std_phi)` ↔ 论文 $\frac{\sigma_\rho\cos\bar\varphi}{\sqrt{N}\text{std}(\varphi)}$ ✅
- σ_z,θ代码 `rho_bar * sigma_theta / (sqrt(N) * std_roll * cos(theta_p))` ↔ 论文 $\frac{\bar\rho\sigma_\theta}{\sqrt{N}\text{std}(r_k)\cos\theta_p}$ ✅
- 合成代码 `inv2 = s_rng**-2 + s_az**-2; s = inv2**-0.5` ↔ 论文 $\sigma_{P_z}^{-2}=\sigma_{z,\rho}^{-2}+\sigma_{z,\theta}^{-2}$ ✅

## 3. ★I-2 可反演性包线C-I~C-IV

### 3.1 论文推导（理论修正_T1-T6.md §3.1）

| 约束 | 公式 | 物理含义 |
|---|---|---|
| C-I | h > 0 | 目标存在 |

| C-IV | $\theta_p \in [\arctan\frac{z_s}{D_t}-\varphi_{\max}, \arctan\frac{z_s}{D_e}+\varphi_{\max}]$ | 下俯角可行范围 |

## 5. ★II-1 σ_h传播（三项偏导）

### 5.1 论文推导（理论基础_完整推导_定稿.md §5.2）

$$\sigma_h^2 = \left(\frac{\partial h}{\partial \rho_{\text{end}}}\right)^2 \sigma_\rho^2 + \left(\frac{\partial h}{\partial D_{\text{far}}}\right)^2 \sigma_{D_t}^2 + \left(\frac{\partial h}{\partial z_s}\right)^2 \sigma_{z_s}^2$$

$$\frac{\partial h}{\partial \rho_{\text{end}}} = \frac{z_s D_{\text{far}} \rho_{\text{end}}}{D_e^3}, \quad \frac{\partial h}{\partial D_{\text{far}}} = -\frac{z_s}{D_e}, \quad \frac{\partial h}{\partial z_s} = 1 - \frac{D_{\text{far}}}{D_e} - \frac{z_s^2 D_{\text{far}}}{D_e^3}$$

> **注意∂h/∂z_s第二项为减号**（2026-10-13审计修正）

### 5.2 代码核查（shadow_f8_fixed.py:280-289）

```python
dDe_drho = rho_end / D_e                    # ∂D_e/∂ρ = ρ/D_e
dh_dDe = zs * D_t / D_e ** 2                # ∂h/∂D_e = z_s·D_far/D_e²
dh_drho = dh_dDe * dDe_drho                  # ∂h/∂ρ = z_s·D_far·ρ/D_e³  ✅

dh_dDt = -zs / D_e                           # ∂h/∂D_far = -z_s/D_e  ✅

dDe_dzs = -zs / D_e                          # ∂D_e/∂z_s = -z_s/D_e
dh_dzs = (1.0 - D_t / D_e) + zs * D_t / D_e**2 * dDe_dzs
#        = (1 - D_far/D_e) + z_s·D_far/D_e² · (-z_s/D_e)
#        = (1 - D_far/D_e) - z_s²·D_far/D_e³  ✅ (减号通过中间变量传播)
```

**逐项对照**：
- ∂h/∂ρ代码 `zs * D_t * rho_end / D_e³` ↔ 论文 $\frac{z_s D_{\text{far}} \rho_{\text{end}}}{D_e^3}$ ✅
- ∂h/∂D_far代码 `-zs/D_e` ↔ 论文 $-\frac{z_s}{D_e}$ ✅
- ∂h/∂z_s代码 `(1 - D_t/D_e) - z_s²·D_t/D_e³` ↔ 论文 $1 - \frac{D_{\text{far}}}{D_e} - \frac{z_s^2 D_{\text{far}}}{D_e^3}$ ✅

**关键验证**：中间变量 `dDe_dzs = -zs/D_e` 的负号通过乘法正确传播到最终减号。这正是2026-10-13审计发现的符号错误修复点——代码使用中间变量而非直接写最终公式，符号传播正确。

### 5.3 独立验证（verify_sigma_h_independent.py:45-69）

## 7. 闭环步骤6：置信度初值

### 7.1 论文推导（创新点内容设计_定稿.md §5闭环数据流）

$$w_i^{(0)} = s_i \cdot g_i \cdot q_i$$

- $s_i$：几何可信度，来自 $\kappa_j = \lambda_3/\lambda_2$（良约束≥0.05→1，弱0.01-0.05→0.5，盲<0.01→0）
- $g_i$：门控因子，来自★I-2包线判定（包线内→1，外→0）

### 7.2 代码核查（closed_loop_theory.py:121-155）

```python
def confidence_init(kappa_j, s_i, g_i, q_i):
    raw = s_i * g_i * q_i                    # ← w_i = s_i·g_i·q_i
    w = np.clip(raw, 0.0, 1.0)
    return w

def kappa_to_s(kappa_j, thresholds=(0.01, 0.05)):
    s[kappa_j >= thresholds[1]] = 1.0        # κ≥0.05 → s=1
    s[(kappa_j >= thresholds[0]) & (kappa_j < thresholds[1])] = 0.5  # 0.01≤κ<0.05 → s=0.5
    s[kappa_j < thresholds[0]] = 0.0          # κ<0.01 → s=0

def envelope_to_g(envelope_flags):
    g[envelope_flags] = 1.0                   # 包线内 → g=1
```

```python
def our_inversion(rho_end, z_s, D_far, valid):
    D_e = np.sqrt(np.maximum(rho_end**2 - z_s**2, 0))   # D_e = sqrt(ρ²-z_s²)
    h_est = z_s * (1 - D_far / D_e)                       # h = z_s(1-D_far/D_e)
    return h_est

def zhou_dual_height(rho_end1, z1, rho_end2, z2, valid1, valid2):
    D_e1 = np.sqrt(np.maximum(rho_end1**2 - z1**2, 0))   # D_e1
    D_e2 = np.sqrt(np.maximum(rho_end2**2 - z2**2, 0))   # D_e2
    numerator = z1 * z2 * (D_e1 - D_e2)                    # z1·z2·(D_e1-D_e2)
    denominator = z2 * D_e1 - z1 * D_e2                    # z2·D_e1 - z1·D_e2
    h_est = numerator / denominator                        # h = num/den
    return h_est
```
