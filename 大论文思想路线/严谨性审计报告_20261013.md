## 1. F-4b v4 阴影语义修正——物理正确 ✅

### 1.1 修改内容

```python
# 旧(错误):
free |= col & (rho > s_start) & (rho < s_end)  # 阴影段=free

# 新(修正):
free |= col & (rho > s_end + dr/2)  # 仅阴影末端之后=free
# 阴影段[s_start, s_end] = unknown → 不删
```

### 1.2 物理审查

**声呐阴影的物理本质**：声波被目标遮挡后，目标后方无回波。阴影段[s_start, s_end]：
- s_start = 目标远边缘（声波被遮挡起点）
- s_end = 阴影末端（声波恢复回波点）

**旧代码错误**：把整个阴影段标为free → 目标后部体素被删
- 因为阴影段实际包含目标后部和目标后方自由空间
- 不能区分"目标本身"和"目标后方"

**新代码正确**：阴影段标为unknown（不删），仅阴影末端之后标free
- 阴影末端之后 = 声呐确实看不到的自由空间 → free ✅
- 阴影段 = 不确定（可能是目标后部或目标后方）→ unknown ✅

### 1.3 文献依据

[Le Gall et al.](https://www.ioa.org.uk/system/files/proceedings/y_le_gall_n_burlet_m_simon_et_al_using_shadows_in_circular_sas_imaging_for_target_analysis.pdf) 确实区分了"阴影区"和"自由空间"。阴影≠自由，阴影是"遮挡区"。

### 1.4 数据验证

V∩从62L→161L → 目标后部被保留 → 物理上正确。
E从0.66→0.15（仅阴影语义修正）→ 改进合理。

**判定：✅ 通过。阴影语义修正物理正确，文献支持。**

## 2. F-4b v4 柱面先验——循环论证 ❌

### 2.1 严重问题

```python
# 第3步: 柱面先验
r_cyl = 0.25          # ← 从哪来? 仿真参数(=GT参数)
h_constraint = h_gt   # ← 从哪来? 仿真真值(=GT)
outside_cylinder = (radial > r_cyl) & in_height
alive[outside_cylinder] = False  # 删柱体外部
below_floor = centers[:, 2] < 0
alive[below_floor] = False

# GT定义:
gt_occ = (radial <= r_cyl) & (dz >= 0) & (dz <= h_pillar)
#                                   ↑  完全相同的r_cyl和h
```

**问题**：柱面先验用了r_cyl=0.25m和h_gt，而GT的定义也是radial≤0.25m且0≤z≤h_gt。

**这等于**：用GT的参数作为先验约束，再用同样的参数定义GT，然后计算与GT的误差。

**结果必然**：V_recon ⊆ V_gt（因为先验比GT更窄或等宽），E=1-V_recon/V_gt的残余仅来自体素离散化。

**这不是"达标"，这是循环论证。** E=0.034不是空间雕刻的精度，而是"体素网格离散化误差"。

### 2.2 正确的做法

柱面先验在**实际应用**中不可能用GT参数。可行的来源：
- 从BA的D_t估计柱心位置 ✅
- 从分割掩码估计柱体宽度 → r_cyl ❌ 但仿真中分割=GT
- 从阴影长度反演高度h → ★II-1 ✅ 这个可以用

**真正应该做的**：
1. 高度约束用**反演值h_inv**（不是h_gt）→ h_inv有误差，体现★II-1的精度
2. 柱面先验**不应使用**，或者用从观测估计的半径
3. 如果一定要用形状先验，应在论文中明确说"假设已知柱半径r"作为前提条件

### 2.3 修正方案

```python
# 修正: 用反演高度(不是GT)
h_constraint = h_inv  # ← 反演值, 不是h_gt
# 柱面先验: 删除(标注为"假设已知r", 不是GT参数)
# 或者: 不用柱面先验, 仅靠阴影语义+高度约束
```

### 2.4 判定

**❌ 必须修正。** 当前E=0.034是循环论证的结果，不是空间雕刻的真实精度。

**实事求是的结果**（仅阴影语义修正+高度约束，不用柱面先验）：
- E应回到~0.15左右（从数据看V∩=161L, V_gt=170L）
- 或者：保留柱面先验，但必须用反演h_inv不是h_gt，且论文明确声明"假设已知柱半径r=0.25m"

## 3. D1 σ_θ标定——诚实但有局限 🟡

   - 理论0.083°仅是beamforming理想精度

3. **结论"足以支撑论文"**：这是判断而非验证

### 3.3 判定

**🟡 可接受，但需修正**：
- 标题改为"理论推导"而非"标定"
- 明确说"真实数据无法标定，用理论推导替代"

但当前没有真正跑BA两轮。`ba_unified.py`有elev_prior接口，但没有"两轮交替"的实验代码。

### 4.3 正确的做法

**方案B（真正实现）**：
