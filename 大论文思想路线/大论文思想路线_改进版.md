## 1. 研究目标

**总目标**：纯二维前视声呐（FLS）条件下的高质量水下三维重建——从声呐图像序列 + 平台里程计，恢复全局一致、几何保真、去噪去伪的三维点云与曲面网格。

**纯声呐取舍的辩护**（写入绪论）：聚焦声呐单模态下的三维重建极限与鲁棒性，主线单一、纵深充分；多传感器/声光融合为独立方向（另有专利），不入本文。代价——仰角信息只能靠"**多视几何 + 声学阴影先验**"两条腿，这正是创新点二存在的必要性。

---

## 2. 核心症结（两个，贯穿全流水线）

1. **几何病态**：FLS 丢失俯仰角，单帧只约束"方位 + 斜距"两维，仰角不可直接观测 → BA 秩亏、易发散。
2. **数据污染**：相干斑、多径、混响致大量伪匹配与杂点，与病态叠加 → 重建畸变、漂浮物。

> 改进版把"可观测性分析"提到基础章：用 $A^TA$（或 Fisher 信息矩阵）最小特征值 λ₃ 量化仰角可观测性，λ₃→0 即病态。这条量化贯穿全文，用于解释"为什么需要视场约束、为什么阴影先验才是真正补可观测性的信息源"。

## 3. 创新点一：置信度贯穿的鲁棒声呐 BA（几何优化层）

### 3.1 定位与可辩护核心
- **定位**：解决 BA 的病态、发散、污染、稀疏成面问题。
- **可辩护核心（主线）**：**"数据关联置信度"作为一个统一量，从 BA 一路贯穿到曲面重建**——不是四个孤立模块，而是"一条置信度流"串起关联、优化、成面。这是相对已有声呐 BA（Huang/Westman）最可主张的原创结构。

### 3.2 模块（1 核心 + 2 辅助 + 1 基础适配）

| 角色 | 模块 | 解决 | 说明 |
|---|---|---|---|
| **核心** | 置信度流：软关联权重 → 联合优化 → **加权曲面重建** | Q1 污染 + Q4 稀疏成面 | 关联可信度 w 既在 BA 里降权伪匹配，又在泊松/法向估计里作权重，全程一致。**防退化**：借鉴 Switchable Constraints，对 w 加惩罚项，避免优化把 w 全压到 0 |
| 基础适配 | 相对球坐标参数化 + **视场箱式硬约束** | Q2 病态 | 相对基准帧球坐标（Westman 思想）；视场约束用 `trf`+bounds 真正实现（初稿是死代码，须修） |
| 辅助 | 位姿-地标联合优化（里程计软约束 + Huber/IRLS） | Q3 漂移 | 里程计作"真实但不完美"软约束 |
| 辅助 | 各向异性观测协方差白化（σ_θ, σ_ρ） | 精度 | 替代统一权重 |

### 3.3 手段 vs 落点（诚实表述，硕士可接受）
- 手段（通用、非创新）：相对球坐标、Huber/IRLS、TRF、加权泊松。
- **落点（本文创新）**：①置信度贯穿 BA→曲面重建的一致性设计（含防塌缩正则）；②面向声呐俯仰病态的视场箱式约束与协方差白化组合。

### 3.4 残留问题（引出创新点二）
纯几何仍解决不了：①仰角只能"限制范围"不能"测量"（视场约束不增可观测性）；②图像域杂波几何上与真实目标难分。

## 4. 创新点二：声学阴影引导的高度反演与语义约束（图像理解层）

### 4.1 定位与可辩护核心
- **唯一核心**：**声学阴影分割 + 高度/仰角反演**，把缺失的第三维以"带不确定度的准观测"注入创新点一的 BA。
- 目标-背景分割、语义一致性关联**降为辅助/消融项**（用于去杂波、提关联，但不作为主打卖点）。

### 4.2 与 Aykin 的新颖性切割（必写）
- 已有：Aykin & Negahdaripour（2013–2017）用手工阈值 + 局部平面假设做阴影几何反演。
- **本文区别**：①**可学习分割（ViT+LoRA）** 自动、鲁棒地提取不规则阴影，替代手工阈值；②反演结果**带不确定度、以软观测注入联合 BA**，与多视重投影共同约束仰角，而非独立几何反演。
- 实验必须**与 Aykin 式手工阈值基线直接对比**。

### 4.3 阴影→高度的正演模型（落到公式，含前提）
- 前提（消除与创新一的逻辑冲突）：**目标坐落于局部近似平面海底**（合理工况，不等于全局平面假设）。
- 几何：由掠射角、量程、俯仰开角与阴影长度/形状反演目标高度 h；输出 h 及其不确定度 σ_h。
- 注入：作为软观测项加入 BA（弱先验、不主导），σ_h 大时自动降权。

### 4.4 分割方法定位（手段层）
- 主方法 ViT+LoRA（SAM 系）参数高效微调，适配声呐小样本 / 阴影不规则；基线 YOLO-seg 对比。
- **强调**：分割是手段，创新落点是"分割结果（尤其阴影）→重建增益"。

## 5. 两创新点耦合与整体闭环

```
声呐图像序列 + 里程计
        │
   [创新点二]  阴影分割→高度先验(核心) ‖ 目标掩码(辅助) ‖ 语义关联(辅助)
        │           （提供仰角先验 + 清洁数据）
        ▼
   [创新点一]  置信度流：软关联 → 视场约束 BA(注入阴影高度先验) → 加权曲面重建
        │
        ▼
   高精度位姿 + 高保真三维点云/网格
```
- 松耦合：无创新二先验时创新一退化为纯几何鲁棒 BA 可独立运行；有阴影高度先验时仰角精度显著提升。

## 6. 关键实验设计（改进版重点）

### 6.1 主打实验：仰角来源消融（纯声呐路线最有说服力）
- 设置：**A 只多视几何 / B 多视 + 阴影高度先验**，在仿真（有高度真值）与真实受控靶上对比。
- 指标：**目标高度/仰角反演误差**、点云 Z 向 RMSE、整体重建 Chamfer/Hausdorff。
- 目的：直接量化"阴影先验对仰角精度的增益"——这是创新点二立身的核心证据。

### 6.2 置信度流消融（创新点一核心）
- 逐步加入：+软关联 / +视场约束 / +联合优化 / +加权曲面重建，量化各步对重投影 RMS、ATE、网格精度、漂浮点数的贡献。
- 与硬剔除（RANSAC）BA、无置信度加权泊松对比。

### 6.3 对标实验
- 阴影反演 vs **Aykin 式手工阈值**。
- 分割主方法 ViT+LoRA vs YOLO-seg。
- 相关工作定位（不实现）：**神经隐式 NeuSIS 类**——说明处同一稠密环节替代范式，本文经典路线的取舍理由（无需逐场景训练、实时、可解释、可注入先验）。

### 6.4 真值与 sim-to-real
- 仿真（HoloOcean/DAVE）出高度/位姿真值做定量；真实场景用**已知尺寸标定靶 / 水箱 CAD 已知物体 / 多波束参考**做受控真值，缓解 sim-to-real 质疑。

### 6.5 评价指标体系
- 位姿：ATE、RPE；几何：重投影 RMS、方位/斜距 RMS、点云/网格 RMSE、Chamfer Distance、Hausdorff；伪影：背景漂浮点数/密度；分割：mIoU/Dice（目标、阴影两类）；核心：高度反演误差。
