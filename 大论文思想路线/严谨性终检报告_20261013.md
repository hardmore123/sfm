## 一、审查发现与修正

### 1. F-4b v5形状先验: D_t来源循环论证 (★★★)

#### 发现

`verify_f4b_v5_shape_prior.py` 旧版第77行:
```python
D_t = meta["config"]["D_t_m"]  # ← GT柱心距离!
```
柱面先验用GT D_t作柱心, 然后评估对GT → **循环论证**。

旧版结果(用GT D_t): E=0.114(虚假达标)

#### 修正

改为从measurements.npy获取BA估计的D_t:
```python
D_far_ba = float(np.mean(meas[:, 3]))  # BA估计的远边缘
D_t = D_far_ba - r_cyl  # 反推柱心(含BA误差, 非GT)
```

修正后结果(用BA估计D_t, 含0.05m误差):
| 场景 | GT D_t(循环) | BA D_t(诚实) | 差异 |
|---|---|---|---|
| M1 | 0.114 | **0.341** | +0.227 |
| M3 | 0.146 | **0.306** | +0.160 |
| M4 | 0.144 | **0.187** | +0.043 |

**E从0.11→0.21-0.34, 不再达标≤0.15, 但仍优于v4(0.53)**
诚实结论: 形状先验有改进但BA估计精度限制了效果

### 2. G6两轮BA: 理论vs实际同义反复 (★★★)

#### 发现

`verify_g6_two_round_ba.py` 第158-159行:
```python
sigma_Pz_2 = 1.0 / np.sqrt(sigma_Pz_1**(-2) + sigma_prior**(-2))
```
第267行"理论值验证"用**同一公式**计算 → 两者必然一致 → **同义反复, 非独立验证**

另外第181行用GT z_s_true融合z_s_ba_2 → **循环论证**(用GT证明接近GT)

#### 修正

1. docstring改为"信息融合公式数值演示, 非独立BA实验"
2. 删除GT z_s_true的使用
3. "理论vs实际一致性"改为"公式=计算(同义反复)"
4. JSON报告加honesty_note

修正后结论:
- σ_Pz从5.08→0.066cm(信息融合数学必然性, 非实验)
- 真实BA实验验证是未来工作(需完整BA数据集)

### 3. gen_scenes D_t_ba: 每帧独立采样 (★★)

#### 发现

旧版在帧循环内每帧重新采样D_t_ba:
```python
for i in range(len(poses_T)):
    D_t_ba = D_T + rng.normal(0, σ_Dt)  # 每帧不同!
```
真实BA中同一地标的估计在所有帧一致(地标在世界坐标系固定)

#### 修正

改为地标级BA估计(全帧共用):
```python
D_t_ba_fixed = D_T + rng.normal(0, σ_Dt)  # 采样一次
for i in range(len(poses_T)):
    D_t_ba = D_t_ba_fixed  # 全帧共用
```
