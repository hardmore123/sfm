# 任务01 · 验证脚本全量回归

## 目标

把 `02_代码/` 下 16 个 `verify_*.py` / `f8_probe_*.py` / `f8_design_*.py` 全跑一遍，
确认整套交付代码回归无失败。

## 怎么做（一条命令）

驱动脚本会自动逐个 subprocess 运行、捕获退出码与输出、自写 UTF-8 日志和汇总，
**你不需要自己一个个跑，也不要用 PowerShell 重定向**（会乱码）。

```powershell
cd F:\sfm\论文代码与数据\02_代码
python _setup_data.py            # 首次执行前跑一次；已跑过可跳过
cd F:\sfm\大论文思想路线\minimax任务分发\工具
$env:PYTHONIOENCODING = "utf-8"
python run_all_verify.py
```

耗时约 5–10 分钟（含场景集验证）。跑完看这两个产物：
- 汇总表：`回报\任务01_自动汇总.md`
- 每脚本原始输出：`回报\日志\<脚本名>.log`

## 已知基线（正确答案）

| 项 | 期望 |
|---|---|
| 通过数 | **16 / 16** |
| 退出码 | 每个脚本都是 `0` |
| 唯一"软标记" | 只有 `verify_f8_fixed.py` 会带"软标记=有"，因为它内部 T4 是一个 ⚠️ 已知近似限制（快速模型 vs 完整渲染差约 32 bin），该脚本自身总判定仍是"通过（T1–T3 必过）" |

## 验收标准（客观）

- **V1**：汇总表底部显示 `通过 16 / 16`。
- **V2**：16 行判定列全部是"通过"。
- **V3**：带软标记的脚本**只有** `verify_f8_fixed.py`（其余均"无"）。

三条全满足 ⇒ 任务01 **通过**。
任一不满足 ⇒ **未通过**，把汇总表整段 + 出问题脚本的 `.log` 关键行抄进回报。
