## 2. 编码坑（已由助手脚本替你规避）

Windows/PowerShell 的 `>`、`*>` 重定向会把中文写成 GBK 或 UTF-16 乱码，控制台显示也常花屏。
**所有助手脚本都在内部用 UTF-8 直接写报告文件**（写到 `回报\日志\`），因此你完全不必用重定向。

你只需要在跑脚本前设一次：

```powershell
$env:PYTHONIOENCODING = "utf-8"
```

然后 `python 助手.py`。报告文件用编辑器以 UTF-8 打开就正常。
**如果控制台里看着是乱码，别管它——以 `回报\日志\` 下的报告文件为准。**

## 3. 铁律（对应本项目踩过的坑，违反即作废）

1. **禁止把结果改成预期值。** 验收不通过就写"未通过"，附真实输出。历史上出过"直接赋值 `actual = theory` 然后报偏差 0%"的事故，这是造假，绝不允许。
2. **禁止改任何 `.py` 代码去"让它通过"。** 你的任务是核查现状，不是修 bug。发现 bug 只记录，交回 Kiro。
3. **命令逐字照抄。** 不要"优化"命令、不要换参数、不要换目录。
4. **一切以文件里的输出为准。** 不要凭记忆或推测填数字。
5. **中文路径**用 PowerShell 时，`Test-Path` 等加 `-LiteralPath`。
