# 任务06 · 文档内部链接与文件引用检查

## 目标

扫有效 `.md` 里的两类本地引用——Markdown 链接 `[文字](路径)` 和 Kiro 文件引用 `#[[file:路径]]`——
核查它们指向的本地文件都存在（无死链）。

> 说明：本项目文档大多用**反引号**引用文件名（如 \`feasibility.py\`），不算"链接"，本检查不覆盖它们。
> 故检查到的链接数不多，属正常；重点是"存在的链接不能是死链"。

## 怎么做（一条命令）

```powershell
cd F:\sfm\大论文思想路线\minimax任务分发\工具
$env:PYTHONIOENCODING = "utf-8"
python check_links.py
```

产物：`回报\日志\check_links.log`（脚本退出码预期 `0`）
