# BA 改进的依据与动机：依据什么、为什么这么改

> 配合 `汇报导览_先读这个.md` 使用。本文回答三个问题：**遇到什么问题 → 依据哪篇论文 → 为什么这样改**。
> 原始论证见 `报告_数据对照/改进方向全清单.md`；效果数字见各测试报告。

---

## 0. 根本约束：为什么声呐 BA 需要"专门"的改进

前视成像声呐（FLS）一次成像只测两个量：**方位角 θ** 和 **斜距 ρ**。
第三维——**俯仰角（elevation，决定目标高度）——在单帧里完全不可观测**：
同一个像素对应空间中一整条"俯仰弧"，弧上任意高度都投影到同一像素。

这条约束决定了：**不能照搬光学相机的 BA**。光学 BA 里三维点是良约束的，
而声呐 BA 里每个路标的高度方向天然病态。下面 4 项改进，本质都是围绕
"如何在俯仰不可观测的前提下，把能估的估准、把不能估的诚实隔离"。

---

## 改进 1：路标参数化 —— 世界笛卡尔 → 相对基准帧球坐标

| | 内容 |
|---|---|
| **遇到的问题** | 基线 `ba_optimize.py` 把路标写成世界系笛卡尔 (x,y,z)。在这种表示下，"俯仰不可观测"这件事被**摊到 x/y/z 三个轴的耦合里**——欠约束路标会沿俯仰弧在 z 方向自由漂移，还会顺带把 x/y 带偏，进而污染位姿。 |
| **依据什么** | **Westman 2018**（声呐 SfM）§III-B、Huang 2016：声呐路标应以**相对基准帧（首次观测该点的帧）的球坐标 (ψ, r, elev)** 参数化，比世界笛卡尔更线性、系统更稳定。 |
| **为什么这样改** | 把不可观测的**俯仰角 elev 显式隔离成一个独立参数**。好处有二：① 病态被限制在 elev 这一维，不再泄漏到水平三轴；② elev 是独立变量后，可以直接对它加范围约束（改进 5）或先验（阴影高度），为后续留接口。 |
| **效果** | 与改进 2 联合作用，路标 Z 向漂移 mean **↓69.5%**（0.269→0.082 m）。 |

## 改进 2：欠约束路标识别与分类建模（最关键的一项）

| | 内容 |
|---|---|
| **遇到的问题** | 基线对所有路标一视同仁做 3-DOF 全优化 + 统一弱先验。基线运行记录里"路标最大位移 2.25 m、集中在 Z 方向"——正是欠约束路标在俯仰方向乱跑，仅靠弱先验压不住。 |
| **依据什么** | **Westman 2018** 的核心结论：**强行三角化欠约束路标会污染估计**。并给出可操作的判别法——对每个路标用其观测构建单点 JᵀJ(3×3)，看特征值。 |
| **为什么这样改** | 不该让"估不准的方向"参与自由优化去迎合观测（那是过拟合）。做法：① 用 **λ₂/λ₃ 特征值判据**把路标分成良约束/欠约束；② 良约束路标正常 3-DOF 优化；③ **欠约束路标把 elev 移出优化状态**，在物理俯仰孔径内网格搜索一个最一致的值并固定，只优化 (ψ, r)；④ 外层坐标下降交替迭代。这样"能估的估、不能估的锁住不乱动"。 |
| **一个有论文价值的发现** | 判据下 **198 个多帧路标全部为欠约束**（λ₂/λ₃ 最小 25.69）。这**量化证明**当前轨迹（前向平移 + 小幅偏航）落在**退化运动区间**，俯仰几何本质不可观测。这不是算法缺陷，而是"为什么必须引入声学阴影这个独立信息源来补高度"的直接实证支点——它把论文主线从"我觉得需要阴影"变成"数据证明必须有阴影"。 |
| **效果 / 诚实说明** | Z 向漂移 ↓69.5%；代价是重投影 RMS 从 1.01 略升到 1.21 px。**这不是退步**——基线那 0.2px 的优势正来自"不受约束地在 Z 方向乱移路标"。以 0.2px 的重投影代价换取 Z 向乱跑下降 70%，符合"**几何可信重于虚低残差**"的取向。 |

## 改进 3：求解效率 —— 数值稠密雅可比 → 解析雅可比 + 稀疏结构

| | 内容 |
|---|---|
| **遇到的问题** | 基线用 `scipy.least_squares` 的**数值差分雅可比 + 稠密求解**。10 帧/217 点还能跑（73 s），但一旦扩大到用满全部观测、每帧建位姿，数值差分会极慢、稠密矩阵吃内存。 |
| **依据什么** | BA 通用理论（Triggs 等 *Bundle Adjustment* ）：BA 的雅可比是**二部图稀疏结构**（每个观测只关联一个位姿 + 一个路标），应利用稀疏性；解析雅可比比数值差分快且准。 |
| **为什么这样改** | 数值差分每次要对全部变量逐个扰动、重算残差，开销随变量数平方增长。改为：① 推导声呐重投影对位姿(6)/路标(3) 的**解析导数**（关键简化：`P_b=Rᵀ(P−t)` 使平移雅可比 = −路标雅可比；旋转用欧拉角解析导数）；② 按二部图结构**向量化填充稀疏 CSR** 交给 trf(lsmr)。 |
| **效果** | 求解 **73.34s → 12.28s（≈6.0× 加速）**；三种方法（数值稠密/数值稀疏/解析稀疏）最终 cost 与重投影 RMS **完全一致 ⇒ 解等价，提速不损精度**。解析雅可比经有限差分校验，最大绝对误差 3.7e-4。 |

## 改进 4：鲁棒性 —— 固定 Huber → GNC + χ² 外点剔除

| | 内容 |
|---|---|
| **遇到的问题** | 基线用固定 Huber（δ=20px）。特征关联难免出错，错关联（外点）会把解拖偏；固定阈值的 Huber 对大偏移外点**仍保留线性尾部影响**，外点越多被拖得越狠，且易陷局部极小。 |
| **依据什么** | **Yang & Carlone 2020（GNC，渐进非凸）**、Sünderhauf 2012（Switchable Constraints）、Agarwal 2013（DCS）、Geman–McClure 冗降核；χ² 门限判外点（α=0.99）。 |
| **为什么这样改** | 用 **GNC-GM**：让鲁棒核的非凸参数 μ 从"近凸"逐步退火到"强非凸"，先求全局大致解、再逐步压制外点，避开局部极小。GNC-GM 是**冗降(redescending)核**——收敛后外点权重趋 0，几乎不再影响解，这是它优于固定 Huber 的根本原因。再配 **χ²(2,0.99)=9.21** 门限剔除外点后用 Huber 重优化内点。 |
| **效果** | 注入外点后内点重投影 RMS：15% 时 4.97→**3.60**，25% 时 8.05→**4.63**，35% 时 10.78→**2.76 px（≈3.9×）**，优势随外点比例增大而扩大。重建图上直观可见（`3_剔除外点_重建对比.png`）：柱体半径误差 22.1→10.7 cm。 |
| **诚实说明** | 25% 档 GNC 位姿误差（0.189m）曾高于 Huber（0.092m），说明 GNC 对 μ/c/尺度估计与局部极小仍敏感，作为边界案例如实保留，不宣称全面占优。 |

## 改进 5（统一版 V6 追加）：视场箱式硬约束

| | 内容 |
|---|---|
| **遇到的问题** | 欠约束路标的 elev 即使网格搜索，良约束路标的 elev 作为自由变量仍可能被优化到物理上不可能的角度（超出声呐俯仰孔径）。 |
| **依据什么** | Huang 2015（退化运动分析）、Westman 2020 Fermat（仰角解的多解性）。 |
| **为什么这样改** | 把良约束路标的 elev 用 `trf` 的箱式 bounds **硬限制在物理俯仰孔径 ±0.30rad 内**。⚠️ 重要认识：**视场约束只限制解的范围、不增加可观测性**（λ₃ 不变）——真正补俯仰信息要靠运动多样性或阴影先验。所以它是"防止解跑到非物理区域"的安全网，不是信息来源。这条界限在汇报里要讲清，否则会被质疑"约束怎么凭空增加了信息"。 |
| **效果** | 统一版 V6 全部 elev 落在孔径内，13 个路标触界（bounds 生效）。 |

## 为什么这个顺序（实施逻辑）

1. **先做 1+2（参数化 + 欠约束建模）**：改动集中在残差构建，直接解决 Z 乱跑，收益最大。
2. **再做 5（视场约束）**：加 bounds 防解跑飞。
3. **然后 4（GNC+χ²）**：提鲁棒。
4. **最后 3（解析稀疏）**：为扩大规模铺路。

实施原则：**每步保留旧逻辑作 fallback，任何一步都不把现在能跑的流程改坏**（例如"检测到球坐标输入才启用欠约束分类"）。这也是为什么代码里 V2 基线被冻结、改进都在新文件里做。

---

## 一句话总结这几项改进的共同逻辑

**声呐俯仰不可观测是硬约束。** 改进 1&2 是"承认它、隔离它、锁住它"（几何可信）；
改进 5 是"别让它跑到非物理区"（安全网）；改进 3&4 是"把能估的部分估得又快又稳"（效率与鲁棒）。
而真正"补上"俯仰信息，要靠另一条独立线索——**声学阴影**（论文创新点二，BA 已留好先验注入接口）。
