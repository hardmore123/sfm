## [1] Zhou et al., Target Height Estimation Using a Single Acoustic Camera (arXiv 2024)

**完整名称**: Target Height Estimation Using a Single Acoustic Camera for Compensation in 2D Seabed Mosaicking

**数据源**: https://arxiv.org/abs/2411.12338

**核心贡献**:
- 提出双高度差分公式，用单个ARIS声呐在两个不同高度pass下估计目标高度
- 公式: h = (D_far2·ρ_end1 - D_far1·ρ_end2) / (ρ_end2 - ρ_end1)
- 在水池实验中验证，ARIS Explorer 3000声呐

**理论依据**:
- 阴影远端ρ_end与声呐高度z_s和目标高度h的几何关系: ρ_end² = (D_far + h·cos(θ_p))² + (z_s - h)²
- 两个不同z_s的pass给出两个方程，解出h
- 需要heave传感器提供z_s

**与本文关系**:
- **R-X5对比基线**: 本文单次通过公式 h = sqrt(ρ_end² - z_s²) - D_far·cos(θ_p) 只需一个pass
- **本文优势**: 不依赖双高度，单次通过MAE 0.116cm vs Zhou 0.273cm
- **本文改进**: 逐波束D_far(非恒定值)，公平对比

## [2] Westman & Kaess, Wide Aperture Sonar Generative Models (IROS 2019)

**完整名称**: Wide Aperture Imaging Sonar Reconstruction using Generative Models

**数据源**: http://www.cs.cmu.edu/~kaess/pub/Westman19iros.pdf

**核心贡献**:
- 用生成模型约束2D FLS重建结果在合理形状空间内
- 解决有限方位孔径(15°)导致的过度膨胀问题
- CMU机器人研究所

**理论依据**:
- 2D FLS方位孔径有限→无法环绕目标→后方自由空间从未被观测→过度膨胀
- 生成模型学习合理形状分布，将重建约束在该分布内
- 概率框架: P(shape|observation) ∝ P(observation|shape)·P(shape)

**与本文关系**:
- **F-4b v5形状先验**: 用柱面先验(r=0.25m)约束重建
- **诊断依据**: 过度膨胀240L(前方130L+上方49L+后方45L)是2D FLS物理局限
- **诚实标注**: "假设已知目标为柱体, 半径r=0.25m"

## [3] Le Gall et al., Using Shadows in Circular SAS

**完整名称**: Using Shadows in Circular SAS Imaging for Target Analysis

**数据源**: https://www.ioa.org.uk/system/files/proceedings/y_le_gall_n_burlet_m_simon_et_al_using_shadows_in_circular_sas_imaging_for_target_analysis.pdf

**核心贡献**:
- 明确阴影区的物理语义: 阴影区≠自由空间
- 阴影区="目标遮挡的无信息区"，不能标为free
- 仅前沿前方(声波确实传播到的区域)可标为free

**理论依据**:
- 声呐阴影=目标遮挡了海底回波→该区域无回波信息
- 但无回波≠自由空间(可能是目标本身遮挡，也可能是其他原因)
- 正确语义: 阴影段=unknown(不删)，前沿前方=free(删)

**与本文关系**:
- **F-4b v4阴影语义修正**: voxel_carve_both中，阴影段标为unknown
- **效果**: V∩从62L→161L(95%召回)，目标后部不再被误删

## [4] Aykin, 3D Target Reconstruction by Space Carving (IEEE JOE 2016)

**完整名称**: 3D Target Reconstruction by Space Carving for Forward-Looking Sonar

**数据源**: https://ieeexplore.ieee.org/abstract/document/7558192

**核心贡献**:
- FLS空间雕刻基线方法
- 用多视角声呐图像，每个视角删除被观测为自由的体素
- AND语义: 任一帧判自由就删除

**理论依据**:
- 声呐波束照射到的区域→有回波→目标存在(occupied)
- 声呐波束前方无回波→自由空间(free)→删除
- 多视角叠加→逐步缩小目标体素范围

**与本文关系**:
- **B0基线**: 仅多视几何(无阴影先验)的对照
- **消融B0 vs B1**: 验证阴影先验的改进幅度
- **AND语义**: 本文voxel_carve_both采用(已修正阴影语义)

## [5] Two-Stage Probabilistic 3D Reconstruction (2025)

- **诚实标注**: 本文G6是公式数值演示，真实BA实验是未来工作

## [6] McGann, riSAM (ICRA 2023)

**完整名称**: Robust Incremental Smoothing and Mapping (riSAM)

**数据源**: https://www.cs.cmu.edu/~kaess/pub/McGann23icra.pdf

**核心贡献**:
- GNC(Graduated Non-Convexity)鲁棒增量平滑
- 用GNC-GM权重替代硬阈值 outlier rejection
- 增量优化框架，支持先验注入

**理论依据**:
- GNC: 从凸近似逐步到非凸目标，避免局部最优
- GM权重: w_i = (σ² + e_i²)^{-1}，大残差→小权重
- 先验注入: 先验作为额外因子加入因子图

**与本文关系**:
- **ba_unified.py GNC-GM**: 已实现GNC鲁棒权重
- **先验注入接口**: elev_prior机制，注入ê_j作为仰角先验
- **G6鲁棒优化**: 两轮BA的理论基础

## [8] Motion Degeneracy Self-supervised Elevation (2023)

**完整名称**: Motion Degeneracy in Self-supervised Learning of Elevation Angle Estimation for 2D Forward-Looking Sonar

**数据源**: https://www.robot.t.u-tokyo.ac.jp/~yamashita/paper/B/B304Final.pdf

**核心贡献**:
- 自监督学习从声呐图像直接估计仰角
- 无需转台标定，从运动中学习方位-仰角映射
- 运动退化时(如纯横移)估计失效

**理论依据**:
- 声呐图像的每列对应一个方位角，行对应距离
- 仰角不可直接观测，但可通过运动(多视角)间接估计
- 运动退化: 无基线变化→仰角不可观测(与本文★I-1同构)

**与本文关系**:
- **D2 σ_θ定性验证**: turtable跨帧强散射点位移一致性
- **诚实结论**: 裁剪图像无空间标定，σ_θ无法定量验证
- **运动退化**: 与本文★I-1可观测性分析的理论同构

## [11] Bayesian MRF Seafloor Reconstruction (Fraunhofer)

**完整名称**: Bayesian Reconstruction of Seafloor Shape from Side-Scan Sonar using Markov Random Field

**数据源**: https://publica.fraunhofer.de/bitstreams/5abf6822-c162-4d42-aa25-fd26c527ac5f/download

**核心贡献**:
- 用马尔可夫随机场(MRF)建模体素间空间相关性
- 观测=似然，先验=空间平滑性，后验=占据概率
- 解决硬雕刻的"非黑即白"问题

**理论依据**:
- MRF: P(voxel_i | neighbors) ∝ exp(-Σ·V(voxel_i, voxel_j))
- 贝叶斯更新: P(occ|obs) = P(obs|occ)·P(occ) / P(obs)
- 空间平滑性先验: 相邻体素倾向相同标签

**与本文关系**:
- **概率占据栅格尝试**: verify_f4b_v5_probabilistic.py
- **失败保留为教训**: 阴影远端D_e=12.86m远超目标远边缘10.85m
- **声呐专家判断**: 阴影远端=海底阴影结束位置，不是目标边界
